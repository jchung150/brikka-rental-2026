제목: [BRIKKA] 중도금 인보이스 송부 — INV-202611-03 (CAD $10,000)

안녕하세요, 테온하우스 담당자님.

9주차 주간보고에서 말씀드린 중도금 **CAD $10,000**의 인보이스를 첨부로 보내드립니다.

청구 근거는 기획 산출물의 완료입니다. Change Order 1호 §7.1은 총액 CAD $42,000이 기획
산출물과 화면 목업을 포함한 Phase 1 전체의 대금임을 확인하고 있으며, 해당 산출물이 지난주로
완료되었습니다. 기능정의서 v1.5, 명세 변경 30건, 개발 측 확인 요청 답변 26건, 계산 검증
141개를 통과한 화면 목업, 기획 완료 보고서입니다. 인보이스에 목록으로 적었습니다.

| 항목 | 금액 |
|---|---|
| 총액 | CAD $42,000 (변동 없음) |
| 기수령 선금 | CAD $21,000 |
| **금차 청구** | **CAD $10,000** |
| 잔금 | CAD $11,000 |

잔금 CAD $11,000은 §7.3 그대로 **Phase 1 최종 검수 수락 후 10일 내**입니다. 총액과 개발 범위,
Phase 1 최종 납품일(2027년 2월 12일)은 변동이 없습니다.

본 청구는 §7.3의 지급 시기를 위와 같이 조정하는 것이므로, **회신으로 확인해 주시면 그 회신을
서면 합의로 보관하겠습니다.** 지급 기일은 발행일로부터 14일, 2026년 11월 30일로 적었습니다.
조정이 필요하시면 알려 주시기 바랍니다.

송금 수수료는 계약에 따라 송금인 부담이며, 중계은행 수수료를 포함해 CAD $10,000이 전액
입금되도록 처리를 부탁드립니다. 송금 정보는 인보이스 하단에 있습니다.

감사합니다.
