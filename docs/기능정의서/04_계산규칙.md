# 4. 계산 규칙

본 장은 금액을 산출하는 규칙을 정의한다.
**오구현 시 금액이 틀어지는 부분이므로 예시 검산을 함께 제시한다.**
구현 후 본 장의 예시로 검증한다.

---

## 4.1 공용 관리비 안분

### 4.1.1 개념

상업용 관리비는 정액이 아니라 **건물 단위 고지서를 유닛에 배분한 결과**다.
단일 계약 정보만으로 금액을 산출할 수 없으며, 동일 건물 내 타 유닛의 면적과 검침값이 필요하다.

| 용어 | 정의 |
|---|---|
| 고지서 총사용량 | 한국전력·상수도사업본부 등이 청구한 건물 전체 사용량 |
| 지침 차이 | 유닛별 계량기 값의 당월 − 직전. **원본이며 수정하지 않는다** |
| 계기배율 | 계량기가 실사용량을 그대로 재지 않을 때의 환산 계수. 기본 1 |
| 개별 사용량 | 지침 차이 × 계기배율 |
| 공용 사용량 합계 | 고지서 총사용량 − Σ 개별 사용량. 복도·승강기·화장실 등에서 쓴 양 |
| 배분배율 | 유닛별 공용부 부담을 가감한다. 기본값 1.0. **0은 「부담 없음」이라는 유효한 값이다** |
| 공용 사용량 | 공용 사용량 합계 중 해당 유닛이 부담하는 몫 |
| 유닛 총사용량 | 개별 사용량 + 공용 사용량 |

### 4.1.2 산정 규칙

```
1) 지침 차이        = 당월 검침값 − 직전 검침값             계량기 보유 유닛만
                      원본이다. **당월 검침값이 없으면 0이다.** 미입력을 뺄셈에 넣지 않는다
   개별 사용량      = 지침 차이 × 계기배율                  → 4.1.3-3
                      계기배율만 곱한다. 배분배율은 곱하지 않는다
                      계량기가 없는 유닛의 개별 사용량은 0이다
2) 공용 사용량 합계  = 고지서 총사용량 − Σ 개별 사용량
3) 기준 공용        = 공용 사용량 합계 × (기준값 ÷ Σ기준값)     배율 1.0일 때의 몫
                      기준값: 배분 기준 = 사용량           → 개별 사용량
                              배분 기준 = 임대면적          → 임대면적
                              배분 기준 = 사용량+임대면적    → 임대면적
4) 공용 사용량      배분배율을 적용한다. **목표값 방식이다. 정규화하지 않는다**
      배율 ≠ 1인 유닛  = 기준 공용 × 배분배율                           지정 몫
      배율 = 1인 유닛  = (공용 사용량 합계 − Σ지정 몫)
                         × (기준 공용 ÷ Σ배율 1인 유닛의 기준 공용)       잔여를 원래 비율대로
      Σ지정 몫이 공용 사용량 합계를 넘거나 배율 1인 유닛이 없으면
                       = 공용 사용량 합계 × (기준값×배율 ÷ Σ기준값×배율)  비례 배분. 경고
5) 유닛 총사용량    = 개별 사용량 + 공용 사용량
6) 부담 비율        = 유닛 총사용량 ÷ 고지서 총사용량
      사용량이 없는 항목(교통유발부담금·정화조청소비 등)은 고지서 총사용량을 1로 보고
      1)~5)를 그대로 적용한다. 개별 사용량이 0이므로 부담 비율 = 공용 사용량 ÷ 1
7) 유닛 청구금액    **공급가액과 부가세를 각각 배분한다**
      유닛 공급가액 = 고지서 공급가액 × 부담 비율     원 미만 절사 → 4.1.8
      유닛 부가세   = 고지서 부가세   × 부담 비율     원 미만 절사
      유닛 청구금액 = 유닛 공급가액 + 유닛 부가세
8) 동일 고지서에서 발생한 타 항목
      전력기금·TV수신료는 한국전력 고지서에 함께 표기되나 **독립 청구항목**이며
      발행 문서가 `일반내역서`라 전기요금과 별도로 전달된다 → 3.3
      배분 기준을 `사용량`으로 두고 참조 항목을 전기요금으로 지정한다.
      전기요금의 **부담 비율**을 그대로 쓴다 → 4.1.3-1
```

> **⚠️ 공용분은 전 유닛이 부담한다. 예외를 두지 않는다.**
> 계량기가 있는 유닛도 복도·화장실·주차장을 쓴다. 개별 계량기는 **전용부 사용량을 실측할
> 뿐 공용부 사용을 면제하지 않는다.** 계량기 보유 유닛을 공용 배분에서 빼면 그 유닛이
> 쓴 공용부를 다른 임차인이 대신 부담하게 된다.
> 특정 유닛을 빼야 한다면 배율을 `0`으로 둔다 → 4.1.7

> **⚠️ 배분배율을 개별 사용량에 곱하지 않는다.**
> 검침값은 계량기가 실측한 전용부 사용량이다. 여기에 배분배율을 곱하면 임차인이 쓰지 않은 양을
> 쓴 것으로 청구하게 되고, 공용 사용량 합계(2단계)까지 함께 틀어진다.
> 배분배율은 **공용 사용량 배분에서만** 사용한다.

> **⚠️ 배분배율은 「정확히 N배」를 의미한다. 정규화하지 않는다.** → 4단계
> 배율 2.3을 넣으면 그 유닛의 공용 사용량이 **정확히 2.3배**가 된다.
> 줄어든 몫은 나머지 유닛이 **원래 비율대로** 다시 나눠 가지며 **합계는 변하지 않는다.**
>
> ```
> 본관1층 기준 공용 740.68 × 2.3 = 1,703.57      지정 몫
> 잔여 2,609.00 − 1,703.57 = 905.43             나머지 13곳이 원래 비율대로
> 합계 2,609.00                                  불변 ✓
> ```
>
> **정규화(기준값×배율 ÷ Σ기준값×배율)하면 안 된다.** 분모가 함께 커져
> 2.3배를 넣어도 1.7배밖에 오르지 않는다. 담당자가 의도한 값과 화면 값이 달라진다.

> **⚠️ 지정한 몫의 합이 공용 사용량 합계를 넘으면 배분할 수 없다.**
> 이때만 **전 유닛 비례 배분**으로 물러서고 화면에 경고한다.
> 배율 1.0인 유닛이 하나도 없는 경우도 같다 — 잔여를 나눠 갈 대상이 없다.

> **⚠️ 배율 0은 유효한 값이다.**
> `0`은 미입력이 아니라 **「이 유닛은 부담하지 않는다」**는 지시다.
> 공용 사용량이 0이 되어 공용분을 배분받지 않으며, 그 몫은 나머지 유닛이 나눠 갖는다.
> 공실·비운영중 유닛을 빼는 수단이다 → 4.1.7. 구현 시 `0`을 falsy로 처리해
> 기본값 1.0으로 되돌리지 않도록 주의한다.

### 4.1.3 건물·항목별 설정

배분 방식은 건물마다 다르다. 건물 상세 관리비 탭(PRO-3)에서 항목별로 설정한다.

| 설정 | 선택지 | 기본값 |
|---|---|---|
| **배분 기준** | 사용량 / 임대면적 / 사용량+임대면적 / 직접 입력 | 임대면적 |
| 계량기 보유 유닛 | 유닛 선택(복수). 유닛마다 계기배율·계량기 공유 지정 | 배분 기준이 계량기를 요구할 때 지정 → 4.1.3-3, 4.1.3-4 |
| **근거 문서** | 고지서 / 내역서 / 계약서 / 집계표 | 고지서 |
| **발행처** | 자유 입력 (한국전력, 상수도사업본부, 경비실 …) | 기준표 값 |

**예외적인 경우에만 지정하는 값**

| 설정 | 선택지 | 용도 |
|---|---|---|
| **참조 항목** | 자기 검침값 / 타 항목 검침값 | 배분 기준이 `사용량`이면서 자체 계량기가 없는 항목에 지정한다. 예: 전력기금은 전기요금을 참조 |

> **공용분 부담 대상은 설정 항목이 아니다.** 언제나 전 유닛이다. 특정 유닛을 빼려면 배율을 `0`으로 둔다 → 4.1.7

**근거 문서**는 그 항목의 금액을 뒷받침하는 문서다. 청구서 발행(PAY-1)의 `근거` 열에
표시되며, 임차인이 산출 근거를 물을 때 무엇을 보여줄지 정한다.

### 4.1.3-1 배분 기준 4종

**계량기 필요 여부는 배분 기준에 포함된다.** 별도 설정으로 두지 않는다.

| 배분 기준 | 계량기 | 개별분 | 공용분 |
|---|---|---|---|
| **사용량** | **전 유닛 필수** | 검침 실측 | **사용량 비율** |
| **임대면적** | 불필요 | 없음 | 임대면적 비율 |
| **사용량+임대면적** | 필수(일부 가능) | 검침 실측 | **임대면적 비율** |
| **직접 입력** | 불필요 | 없음 | 배분하지 않음 → 4.1.3-2 |

```
전기요금       전 유닛 계량기. 공용분도 사용량 비율        →  사용량
수도요금       1층만 계량기. 공용분은 면적 비율           →  사용량+임대면적
정화조청소비    계량기 없음. 전액 면적 비율               →  임대면적
주차비        면적·사용량과 무관                       →  직접 입력
```

> **⚠️ `사용량`은 전 유닛이 계량기를 보유해야 한다.**
> 일부만 보유하면 계량기 없는 유닛의 **기준값(개별 사용량)이 0**이 되어 공용분을 한 푼도 부담하지
> 않고, 그 몫을 계량기 보유 유닛이 대신 낸다.
> 이 경우 **`사용량+임대면적`을 쓴다.** 설정 화면에서 경고로 안내한다.
> 계량기 공유 유닛은 경고 대상에서 제외한다 → 4.1.3-4

**참조 항목**

> **참조 항목은 배분이 참조 대상에 완전히 종속된다.**
> 검침도 조정도 하지 않으며 정산 화면에 해당 절을 두지 않는다.
> 부담 비율을 바꾸려면 참조 대상 항목의 조정 절에서 바꾼다.
>
> **작업 순서가 강제된다.** 참조 대상의 정산이 끝나야 참조 항목의 금액이 확정된다.
> 참조 항목은 자체 입력이 없어 완료된 것처럼 보이므로 **참조 대상의 상태를 물려받아
> 화면에 표시한다** → PAY-10
>
> **참조하는 것은 `부담 비율`(총 사용량 ÷ 고지서 총사용량)이다.**
> `공용 배분 비율`(공용분만)이 아니다. 전력기금은 전기 사용량 **전체**에 비례해
> 부과되므로, 개별 사용분을 빼고 나누면 전기를 많이 쓴 유닛이 적게 내게 된다.

### 4.1.3-2 배분 기준 `직접 입력`

**안분하지 않는 항목이 있다.** 면적이나 사용량과 무관하게 계약별 금액이 개별로 정해진다.

```
주차비   층별 무료 주차 대수를 넘는 만큼만 대당 요금을 매긴다
         101호 무료 2대 / 사용 4대 → 초과 2대 × 50,000원 = 100,000원
         면적이 넓다고 더 내지 않고, 사용량 계량기도 없다
```

| 항목 | 일반 항목 | 직접 입력 항목 |
|---|---|---|
| 고지서 | 있다. 총액을 안분한다 | **없다** |
| 공급가액 | 고지서 절에서 입력 | **계약별 입력 금액의 합.** 직접 수정할 수 없다 |
| 검침 | 계량기 보유 유닛 | 하지 않는다 |
| 배율 | 공용 사용량에 적용 | **쓰지 않는다** |
| PAY-10 항목 페이지 | 고지서 → (검침) → 조정 → 산출 | **금액 입력 → 산출** |
| 검증 (4.1.8) | 임차인 + 공실 = 고지서 총금액 | 입력 합계가 곧 총액이므로 항상 성립한다 |

- 계량기·참조 항목 설정을 쓰지 않는다
- 계약이 없는 유닛에 금액을 넣을 수 없다. 청구 대상이 없기 때문이다
- 산출 근거(무료 대수, 초과 대수, 단가)는 **근거 문서에 남긴다.** 1차는 금액만 입력한다
- 입력 금액은 공급가액이다. 과세 항목이면 부가세 = 입력 합계 × 10%. 계약별 부가세는 입력 금액 비율로 나누고
  원 미만을 절사하며, 잔차는 금액이 가장 큰 계약에 더한다

**추가 청구**(CTR-3)는 안분하지 않는다. 입력 금액은 **부가세 포함**이다.
발행 문서가 세금계산서면 공급가액 = 금액 × 10 ÷ 11(원 미만 절사), 부가세 = 금액 − 공급가액. 그 외는 부가세 0이다

> **[2차]** 층별 무료 주차 대수와 대당 단가를 시스템에서 관리하고 초과분을 자동 계산하는
> 것은 2차 범위다. 1차는 경비실 집계 결과를 금액으로 입력한다.

### 4.1.3-3 계기배율

**계량기가 실사용량을 그대로 재지 않는 경우가 있다.** 변류기(CT)를 거치는 계량기는
지침이 실사용량의 일정 비율로 표시되며, **환산 계수를 곱해야 실사용량이 된다.**

```
본관1층 에스씨케이컴퍼니   1/30 계량기
  지침 차이   2,106.50 − 1,774.40 = 332.10
  계기배율    30
  개별 사용량 332.10 × 30 = 9,963.0 kWh
```

- **유닛 × 청구항목 단위로 저장한다.** 계량기의 고정 속성이며 회차마다 입력하지 않는다
- **두 곳에서 입력한다.** 건물 관리비 탭(PRO-3)의 계량기 보유 유닛 목록,
  그리고 정산의 검침 입력 절. 같은 값이며 어느 쪽에서 고쳐도 된다
- 기본값은 `1`이다. 대부분의 계량기는 지침이 곧 사용량이다
- 계량기를 교체하면 배율이 바뀔 수 있다. **확정된 과거 회차는 스냅샷에 남으므로 영향받지 않는다** → PAY-10
- **미확정 회차에 검침값이 입력된 유닛은 계량기 보유 유닛에서 뺄 수 없다.** 담당자가 검침값을 먼저 지운 뒤 뺀다.
  실수로 빼서 값을 잃는 일을 막는다. 확정된 회차의 검침값은 스냅샷이므로 영향이 없다
- 검침 입력 절은 `개별 사용량` · `계량기 배율` · `증감` 순으로 둔다.
  개별 사용량이 **배율이 반영된 현재 값**이고 증감이 배율로 더해진 양이다.
  조정 절의 `공용 사용량` · `배율` · `증감`과 같은 구조다

> **⚠️ 계기배율과 배분배율은 다르다.**
> 화면에서는 `계량기 배율`(검침 입력)과 `배율`(조정)로 구분해 표기한다.
>
> | | 계기배율 | 배분배율 |
> |---|---|---|
> | 화면 표기 | `계량기 배율` (검침 입력 절) | `배율` (조정 절) |
> | 성격 | **물리적 환산.** 계량기가 1/30로 잰다 | **정책적 배분.** 1층이 공용부를 많이 쓴다 |
> | 적용 대상 | 개별 사용량 | 공용 사용량 |
> | 저장 위치 | 계량기 설정. 상시 | 정산 회차. 회차마다 |
> | 바뀌면 | 공용 사용량 합계가 바뀐다 | 합계는 불변, 유닛 간 비율만 바뀐다 |
>
> **「배분배율을 개별 사용량에 곱하지 않는다」는 원칙은 그대로다.**
> 계기배율은 실측값을 임의로 부풀리는 것이 아니라 **계량기가 축소해 표시한 값을 복원**하는
> 것이므로 그 원칙에 어긋나지 않는다.

**배율을 빠뜨리면 조용히 틀린다.** 실제 데이터에서 본관1층 배율을 적용하지 않으면
개별 사용량이 332kWh로 잡혀 공용 사용량이 **32.5%**로 부푼다. 배율을 적용하면 **6.9%**가 된다.
검증(4.1.8)은 합계만 보므로 이 오류를 잡지 못한다.

### 4.1.3-4 계량기 공유

**두 유닛이 한 공간을 쓰며 계량기가 하나뿐인 경우가 있다.**

```
본관301호 고우컴퍼니 · 본관302호 유니버셜
  한 공간을 함께 쓰고 전기 계량기는 302호에 하나뿐이다
  301호 사용분은 302호 지침에 이미 포함되어 있다
```

- 공유 유닛은 **`계량기 없음`이 아니라 `계량기 공유`다.** 검침 입력 절에 상대 유닛을 표시한다
- **배분 기준이 `사용량`일 때 공유 유닛의 기준값이 0인 것은 정상이다.**
  그 사용분은 이미 상대 유닛의 개별 사용량으로 청구되었다
- 따라서 **`사용량` 기준의 「일부만 계량기 보유」 경고 대상에서 제외한다** → 4.1.3-1
  공유로 지정하지 않으면 오탐이 떠서 경고가 무뎌진다
- **항목마다 다르다.** 전기는 공유하지만 수도는 각자 부담할 수 있다.
  면적 기준 항목에서는 공유 유닛도 자기 면적대로 부담한다

```
본관301호   전기요금  302호 계량기 공유  → 기준값 0, 청구 0
            수도요금  면적 기준         → 165㎡ 몫 부담 (302호가 대납) → 4.1.7-3
```

> **⚠️ 계량기 없음 · 계량기 공유 · 전용부 직접 납부를 구분한다.** 셋 다 계량기를 지정하지 않는다.
>
> | | 사용분이 | 사용량 기준에서 | 면적 기준에서 |
> |---|---|---|---|
> | 계량기 없음 | **공용분에 섞여 있다** | 기준값 0 → **다른 유닛이 대신 낸다. 경고** | 면적대로 부담 |
> | 계량기 공유 | **상대 유닛 지침에 포함** | 기준값 0 → **정상** | 면적대로 부담 |
> | 전용부 직접 납부 → 4.1.7-2 | **고지서에 없다** | 기준값 0 → 공용분도 안 낸다. 면적 기준을 쓴다 | 면적대로 공용분 부담 |

### 4.1.4 검산 예시 1 — 전기 (건물 일괄, 전 유닛 계량기)

```
고지서      10,000 kWh / 5,000,000원
유닛        A 검침 3,000   B 검침 2,000   C 검침 1,000
배율   A 1.0   B 1.0   C 2.0     ← C는 1층 상가. 공용 화장실·주차장 사용이 많아 부담 가중
설정        배분 기준 사용량 (전 유닛 계량기)
```

| 단계 | A | B | C | 합계 |
|---|---|---|---|---|
| 1) 개별 사용량 | 3,000 | 2,000 | 1,000 | 6,000 |
| 2) 공용 사용량 합계 | | | | **4,000** |
| 3) 기준 공용 (배율 1.0) | 2,000.0 | 1,333.3 | 666.7 | 4,000 |
| 4) 공용 사용량 | 1,600.0 | 1,066.7 | **1,333.3** (666.7×2.0) | 4,000 ✓ |
| 5) 유닛 총사용량 | 4,600.0 | 3,066.7 | 2,333.3 | **10,000** ✓ |
| 6) 부담 비율 | 46.0% | 30.7% | 23.3% | 100% |
| 7) 청구금액 | 2,300,001 (절사 +1) | 1,533,333 | 1,166,666 | **5,000,000** ✓ |

4단계: C는 지정 몫 666.7 × 2.0 = 1,333.3. 잔여 4,000 − 1,333.3 = 2,666.7을
A·B가 기준 공용 비율(2,000 : 1,333.3)대로 나눈다.

C의 배율 2.0은 C의 **공용 사용량에만** 작용한다. 검침 1,000kWh는 그대로 C에게 청구된다.
배율이 1.0일 때 C의 공용 사용량은 666.7인데, 2.0으로 올리면 **정확히 2배인 1,333.3**이 되고
그만큼 A·B의 공용 사용량이 줄어든다. 합계 4,000kWh는 변하지 않는다.

7단계: 원 미만 절사 후 합계가 4,999,999원이므로 잔차 1원을 부담 비율이 가장 큰 A에 더한다 → 4.1.8
(예시는 단순화를 위해 총액 하나로 계산했다. 실제로는 공급가액과 부가세를 각각 배분한다)

### 4.1.5 검산 예시 2 — 전기 (공용부만 고지되는 건물)

**실제 운영 중인 건물의 방식이다.** 카즈하타워은 전용부 전기를 임차인이 한국전력과 직접
계약해 각자 납부하고, 건물은 **공용부 고지서만 수령해 안분**한다.

**건물이 임차인 계량기를 읽을 이유가 없다.** 전용부 사용량은 한국전력과 임차인 사이의
일이고, 건물이 나눌 대상은 공용부 고지서 전액뿐이다.
따라서 **계량기를 쓰지 않고 배분 기준을 `임대면적`으로 둔다.**

```
고지서      3,000 kWh / 1,500,000원       ← 이미 공용분
설정        배분 기준 임대면적 · 계량기 없음
유닛        A 100㎡   B 200㎡   C 300㎡   (배율 C 1.5 — 1층 상가)
```

| 단계 | A | B | C | 합계 |
|---|---|---|---|---|
| 1) 개별 사용량 | — | — | — | 계량기 없음 |
| 2) 공용 사용량 합계 | | | | **3,000** (Σ개별이 0이므로 총사용량 그대로) |
| 3) 기준 공용 (면적 비율) | 500 | 1,000 | 1,500 | 3,000 |
| 4) 공용 사용량 | 250 | 500 | **2,250** (1,500×1.5) | 3,000 ✓ |
| 5) 유닛 총사용량 | 250 | 500 | 2,250 | 3,000 ✓ |
| 6) 부담 비율 | 8.3% | 16.7% | 75.0% | 100% |
| 7) 청구금액 | 125,000 | 250,000 | 1,125,000 | **1,500,000** ✓ |

C의 지정 몫 2,250을 뺀 잔여 750을 A·B가 100 : 200으로 나눈다.
**배율 1.5가 C의 몫을 정확히 1.5배로 만들고, 늘어난 750은 전부 A·B가 덜 낸다.**
면적이 큰 유닛에 배율을 주면 나머지 유닛의 부담이 크게 줄어든다는 점을 설정 시 유의한다.

> 본 예시는 **건물 전 유닛**이 전용부를 직접 납부해 고지서 자체가 공용분만 발행되는 경우다.
> 일부 유닛만 직접 납부하는 경우 → 4.1.7-2

> **`사용분 청구 여부` 설정을 두지 않는다.**
> 「계량기는 있는데 개별분을 청구하지 않는다」는 조합이 필요해 보이지만, 그 경우
> 건물이 남의 계량기를 읽어야 하고 그럴 근거도 없다. 공용부만 고지된다면
> **계량기 없이 면적으로 나누면 된다.** 배분 기준 4종으로 모든 경우가 표현된다 → 4.1.3-1

### 4.1.6 검산 예시 3 — 수도요금 (일부 유닛만 계량기)

```
고지서      1,000 톤 / 2,000,000원
1층 카페    계량기 있음. 검침 300톤. 임대면적 100㎡. 배율 1.5
                                              ← 커피숍. 공용 화장실 급수도 많이 쓴다
2층         계량기 없음. 임대면적 200㎡
3층         계량기 없음. 임대면적 300㎡
설정        배분 기준 사용량+임대면적
```

**1층도 공용분을 부담한다.** 계량기는 전용부 300톤을 실측할 뿐이고,
공용 화장실 급수는 그 계량기를 지나지 않는다.

| 단계 | 1층 | 2층 | 3층 | 합계 |
|---|---|---|---|---|
| 1) 개별 사용량 | 300 | — | — | 300 |
| 2) 공용 사용량 합계 | | | | **700** |
| 3) 기준 공용 (면적 비율) | 116.7 | 233.3 | 350.0 | 700 |
| 4) 공용 사용량 | **175.0** (116.7×1.5) | 210.0 | 315.0 | 700 ✓ |
| 5) 유닛 총사용량 | 475.0 | 210.0 | 315.0 | **1,000** ✓ |
| 6) 부담 비율 | 47.5% | 21.0% | 31.5% | 100% |
| 7) 청구금액 | 950,000 | 420,000 | 630,000 | **2,000,000** ✓ |

1층은 개별 300톤에 더해 공용 175톤을 부담한다.
배율을 1.5로 올린 만큼 2·3층 부담이 줄고, 합계 700톤은 변하지 않는다.

### 4.1.7 공실 유닛 처리

**공실 유닛도 다른 유닛과 동일하게 배율대로 안분에 참여한다. 별도 규칙을 두지 않는다.**
공실 유닛에 산출된 금액은 청구서를 생성하지 않으며 건축주가 부담한다.

결과는 배분 기준에 따라 달라진다.

| 배분 기준 | 공실 유닛의 몫 | 결과 |
|---|---|---|
| 사용량 | 개별 사용량이 0에 가까워 몫도 0에 가까움 | 공용분 대부분을 임차 유닛이 부담. 공실이 늘면 임차인 부담이 증가 |
| 임대면적 · 사용량+임대면적 | 임대면적만큼 몫 발생 | 공실 면적분을 건축주가 부담 |
| 직접 입력 | 계약이 없으므로 금액을 넣을 수 없다 | 공실분 없음 |

**어느 기준을 쓸지는 건물·항목별로 설정한다**(PRO-3 관리비 탭). 임대차계약서의 관리비 조항에 맞춘다.
예: A건물은 공용 전기요금을 사용량, 수도요금을 면적으로 배분하고 B건물은 그 반대로 설정할 수 있다.

### 공실을 안분에서 빼는 방법 — 배율 0

건물 전체 사용량이므로 공실·비운영중 유닛도 부담하는 것이 원칙이다. 다만 **건물마다 실무가
다르므로 회차 단위로 뺄 수 있어야 한다.** PAY-10 항목 페이지의 조정 절에서 해당 유닛의 배율을 `0`으로 둔다.

```
공용 사용량 = 기준 공용 × 0 = 0   →  공용 사용량 배분 없음
그 몫은 배율 1.0인 유닛이 원래 비율대로 나눠 갖는다. 고지서 총액은 변하지 않는다
```

공용부를 전혀 쓰지 않는 유닛(예: 출입구가 따로 있는 별채 상가)도 같은 방법으로 뺀다. 이것이 공용분에서 유닛을 빼는 **유일한 방법**이다.

배율 0으로 공실을 빼면 **공실·미청구분이 0이 되고 전액이 임차 유닛에 청구된다.**
건축주 부담을 없애는 대신 임차인 부담이 커지므로 임대차계약서 관리비 조항과 일치하는지 확인한다.

검산 (예시 1에 공실 D호 추가. 배분 기준 사용량)

```
D호 공실 · 개별 사용량 100 (대기전력 등)

개별 사용량      A 3,000    B 2,000    C 1,000        D 100      합 6,100
공용 사용량 합계  10,000 − 6,100 = 3,900
기준 공용        A 1,918.0  B 1,278.7  C 639.3        D 63.9     합 3,900
공용 사용량      A 1,542.0  B 1,028.0  C 1,278.7(×2.0) D 51.4     합 3,900 ✓
유닛 총사용량    A 4,542.0  B 3,028.0  C 2,278.7      D 151.4    합 10,000 ✓

D호 몫 151.4kWh(75,699원)는 청구서를 생성하지 않는다 → 공실·미청구분
```

### 4.1.7-2 전용부를 임차인이 직접 납부하는 유닛

**임차인이 한전·상수도사업본부 등과 직접 계약해 전용부 요금을 따로 내는 경우가 있다.**
그 유닛의 전용부 사용량은 건물 고지서에 **처음부터 들어 있지 않다.** 고지서에는 공용부(와 다른 유닛 전용부)만 있다.

**별도 설정을 두지 않는다. 그 유닛에 계량기를 지정하지 않으면 된다.**
- 개별 사용량이 0이므로 전용부를 두 번 청구하지 않는다
- **공용분은 부담한다.** 직접 납부하는 임차인도 복도·엘리베이터·화장실을 쓴다
- 배분 기준은 `임대면적` 또는 `사용량+임대면적`을 쓴다. `사용량`이면 기준값이 0이 되어 공용분도 내지 않는다 → 4.1.3
- 전 유닛이 직접 납부해 고지서가 공용분만 오는 건물은 배분 기준 `임대면적`, 계량기 없음으로 둔다 → 4.1.5
- 공용부도 전혀 쓰지 않는 유닛만 PAY-10 조정에서 배율 `0`으로 뺀다 → 4.1.7

**건물 계량기 내부에 있으면서 별도 정산하는 경우와 다르다.**
그때는 고지서에 사용량이 포함되므로 계량기를 지정해 개별 사용량을 청구하고 나머지를 공용분으로 배분한다 → 4.1.6

검산 (예시 3에서 1층 카페가 수도를 직접 계약. 배율 1.0)

```
고지서      700톤 / 1,400,000원          ← 1층 전용 300톤이 빠진 금액으로 발행됨
1층 카페    계량기 지정 안 함 (직접 계약). 임대면적 100㎡
2층         계량기 없음. 임대면적 200㎡
3층         계량기 없음. 임대면적 300㎡
설정        배분 기준 사용량+임대면적

개별 사용량      전 유닛 0                     합 0
공용 사용량      1층 116.7  2층 233.3  3층 350.0   합 700 ✓
청구금액        1층 233,333  2층 466,666  3층 700,001 (절사 +1)   합 1,400,000 ✓
```

1층은 전용부 요금을 상수도사업본부에 직접 내고, 건물에는 공용분 116.7톤 몫만 낸다.

### 4.1.7-3 정산액 대납 계약

**한 유닛의 정산액을 다른 계약이 부담하는 경우가 있다.**

```
본관301호 고우컴퍼니    임대료 396,000원(부가세 포함)만 청구
본관302호 유니버셜      자기 임대료·관리비 + 301호의 정산액까지 부담
                      두 계약의 실질 주인이 같다
```

**계약에 `정산액 대납 계약`을 지정한다.** 지정하면 그 계약의 정산 항목은 청구되지 않고,
지정된 계약의 청구서에 **`대납`**으로 실린다.

```
산출   유닛 기준으로 정상 계산한다. 안분 모수에서 빼지 않는다
청구   산출 결과를 지정된 계약으로 옮긴다
표시   받는 계약의 청구서에 「본관301호|고우컴퍼니 대납」으로 항목을 구분한다
```

**배율 0과 다르다.** 둘을 혼동하지 않는다.

| | 고지서에 그 유닛 사용량이 | 안분 모수에서 | 그 몫은 |
|---|---|---|---|
| **대납** | 포함되어 있다 | **뺀다 ✕** | **지정된 계약이 낸다** |
| 배율 0 → 4.1.7 | 포함되어 있다 | 뺀다 ○ | 나머지 유닛이 나눠 갖는다 |

> **⚠️ 대납은 산출을 바꾸지 않는다.** 유닛 기준 안분 결과는 그대로이고 **청구 대상만 옮긴다.**
> 배율 0으로 처리하면 그 몫이 **전 유닛에 흩어져** 지정된 계약만 부담하는 결과가 되지 않는다.

- 고정액 항목은 옮기지 않는다. 계약에 등록된 약정액이므로 그 계약에 청구한다.
  301호가 관리비를 내지 않으므로 **301호 계약의 고정관리비는 0원으로 둔다.** 0원은 청구하지 않는다 → PAY-3
- 받는 계약의 청구서에서 자기 몫과 대납분을 **항목 단위로 구분해 표시한다.**
  임차인이 무엇을 왜 내는지 알 수 있어야 한다
- 계약이 종료되면 대납 지정도 끝난다. 계약 속성이기 때문이다

### 4.1.8 절사와 검증

**절사 규칙**

```
유닛 공급가액 = 고지서 공급가액 × 부담 비율,  원 미만 절사
유닛 부가세   = 고지서 부가세   × 부담 비율,  원 미만 절사
```

> **⚠️ 공급가액과 부가세를 합쳐서 배분하지 않는다.**
> 합계만 배분하면 유닛별 부가세를 알 수 없어 **세금계산서를 만들 수 없다.**
> 두 축을 각각 배분하고 잔차도 각각 처리한다.

유닛마다 절사하므로 **합계는 언제나 고지서보다 몇 원 적다.** 유닛 11개면 최대 10원이다.

**잔차는 부담 비율이 가장 큰 유닛에 더한다. 공급가액과 부가세 각각.**
단, **일할 계산을 적용한 항목은 잔차를 유닛에 더하지 않고 공실·미청구분으로 보낸다** → 4.1.9

```
공급가액 잔차 = 고지서 공급가액 − Σ 유닛 공급가액     언제나 0 이상
부가세 잔차   = 고지서 부가세   − Σ 유닛 부가세
대상 = 부담 비율이 가장 큰 유닛
       동률이면 유닛 정렬 순서가 앞선 유닛
```

산출 결과에 잔차를 받은 유닛과 금액을 표시한다(`절사 +5원`).
임차인이 물으면 답할 수 있어야 한다.

**왜 이 방식인가**

| 안 | 평가 |
|---|---|
| **최대 몫 유닛에 가산** ✅ | 결정적이다. 같은 입력이면 언제나 같은 유닛이 부담한다. 규칙을 한 줄로 설명할 수 있고, 큰 몫을 받는 유닛이 몇 원을 더 내는 것이 작은 유닛이 내는 것보다 설명하기 쉽다 |
| 최대 잔여법 (소수부가 큰 순서로 1원씩) | 수학적으로 가장 공평하나 매월 대상이 바뀐다. 「왜 이번 달은 301호가 1원 더 냈나」를 설명해야 한다. 몇 원을 위해 감수할 복잡성이 아니다 |
| 공실·미청구분(건축주)에 가산 | 임차인 청구액이 순수 계산값이 되어 깔끔하나, **공실이 없으면 성립하지 않아** 규칙이 둘이 된다 |
| 차액을 허용하고 검증을 완화 | 원장 합계가 고지서와 어긋난다. 회계상 받아들일 수 없다 |

**반올림을 쓰지 않는 이유**
반올림하면 합계가 고지서를 **초과할 수도** 있어 잔차의 부호가 양·음 양쪽으로 생긴다.
절사로 고정하면 언제나 부족하므로 **더하기만** 하면 되고, 임차인에게 과다 청구되는
경우가 원천적으로 없다.

**검증 규칙**

잔차 배분 후 항목별로 다음을 검증한다. **하나라도 어긋나면 확정할 수 없다.**

```
① 임차인 공급가액 합계 + 공실·미청구분 = 고지서 공급가액
①-2 임차인 부가세 합계 + 공실·미청구분 = 고지서 부가세
② 모든 유닛의 개별 사용량 ≥ 0        당월 < 직전이면 계량기 교체 또는 오입력
③ 모든 유닛의 청구금액 ≥ 0
```

②를 두는 이유는 음수 사용량이 **조용히 전체를 망가뜨리기 때문**이다.
한 유닛의 사용량이 음수면 Σ개별이 줄어 공용 사용량 합계가 부풀고, 그 유닛의 청구금액이
음수가 되어 다른 임차인이 대신 부담하게 된다. ①은 그래도 성립하므로 잡히지 않는다.

잔차를 배분했으므로 정상적인 경우 언제나 일치한다.
따라서 이 검증에 걸린다는 것은 **절사가 아니라 실제 오류**라는 뜻이다.

산출 결과에 `공실·미청구분`을 별도 행으로 표시해 건축주 부담액을 확인할 수 있게 한다.

### 4.1.9 부과 기간과 일할 계산

전기·수도 고지서의 부과 기간은 달력 월과 어긋나는 경우가 많다(예: 7/10~8/9, 수도는 격월).
**고지서를 입력할 때 부과 기간(부과 시작일 ~ 부과 종료일)을 받는다.** 항목마다 기간이 다르므로 고지서마다 받는다.

**입주·퇴거로 부과 기간의 일부만 쓴 계약은 일할 계산기로 그 몫을 줄인다.** 자동으로 줄이지 않는다.
입주 검침값이 없어 계량기 사용량도 입주 전 사용분과 섞여 있으므로, 담당자가 산출 결과를 보고 적용한다.

```
부과 일수   = 부과 종료일 − 부과 시작일 + 1        양 끝 포함
적용 일수   = 적용 종료일 − 적용 시작일 + 1        양 끝 포함
조정 공급가액 = 그 계약의 공급가액 몫(버리기 전) × 적용 일수 ÷ 부과 일수   원 미만 버림
조정 부가세   = 그 계약의 부가세 몫(버리기 전)   × 적용 일수 ÷ 부과 일수   원 미만 버림
```

**일할이 하나라도 있는 항목은 임차인 금액을 고지서 금액에 억지로 맞추지 않는다.** 순서는 이렇다.
1. 계약마다 버리기 전 몫(고지서 금액 × 부담 비율)을 구한다
2. 일할한 계약은 몫을 줄인다
3. 모든 계약의 원 미만을 버린다
4. 고지서 금액에서 임차인 금액 합계를 뺀 나머지는 **모두 건물주(공실·미청구분)**가 가져간다. 줄인 몫과 버린 원 단위가 함께 들어간다.
   4.1.8의 「남는 원 단위를 부담 비율이 가장 큰 계약에 붙이는」 처리는 하지 않는다

- 적용 시작일 기본값은 그 항목의 기산일(부과 기간보다 앞이면 부과 시작일), 적용 종료일 기본값은 계약 종료일(부과 기간보다 뒤면 부과 종료일)이다
- **계산값은 담당자가 고칠 수 있다.** 원래 금액보다 크게 할 수는 없다. 고친 금액은 그대로 고정하고(부가세는 원래 비율로 나눔), 나머지는 같은 순서로 다시 계산한다
- 사유는 `일할 9/31일 (08.01~08.09)`로 자동으로 채우고 고칠 수 있다
- **줄어든 몫은 공실·미청구분(건물주 부담)으로 간다.** 그 기간에 유닛을 쓴 임차인이 없기 때문이다. 고지서 합계 검증(4.1.8)은 그대로 맞는다.
  **다른 임차인의 금액은 늘지 않는다.** 산출 결과 표에는 `건물주 부담` 줄을 따로 두어, 줄인 돈이 어디로 갔는지 보인다

**검산 예시**

```
전기요금 고지서 부과 기간  7/10 ~ 8/9          = 31일
새 임차인 기산일           8/1  → 8/1 ~ 8/9    = 9일
그 계약의 몫(버리기 전)    공급가액 25,914.55 · 부가세 2,591.45   (합 28,506원)
조정 공급가액              25,914.55 × 9 ÷ 31 = 7,523.58 → 7,523원
조정 부가세                 2,591.45 × 9 ÷ 31 =   752.36 →   752원
조정 금액                  8,275원
공실·미청구분으로 가는 몫  28,506 − 8,275 = 20,231원 (다른 계약에서 버린 원 단위도 공실분으로 간다)
```

**고지서가 나오기 전에 퇴거하는 계약**
- 시스템이 추정하지 않는다. 담당자가 직전 6개월 평균 등으로 직접 계산해 퇴거 때 **추가 청구**로 받거나 보증금에서 뺀다 → CTR-3
- 나중에 그 기간의 고지서가 오면, 이미 추정액을 받았으므로 일할 계산기에서 그 유닛 금액을 0원으로 고치고 사유 `퇴거 때 추정액으로 받음`을 남긴다

## 4.2 일할 계산

### 4.2.1 원칙

해당 기간의 **실일수**를 기준으로 한다. **시작일과 퇴거일을 모두 포함**한다.

```
청구액 = 월 약정액 × 청구 대상 일수 ÷ 해당 기간 총일수
```

30일 고정 방식을 사용하지 않는다. 달마다 초과 징수되어 연간 합계가 어긋나기 때문이다.

### 4.2.2 첫 달

```
임대료 7,000,000원 · 계약시작일 2026-08-13

대상 기간   8/13 ~ 8/31 = 19일     (시작일 포함)
총일수      8월 = 31일
청구액      7,000,000 × 19 ÷ 31 = 4,290,322.58 → 4,290,322원
```

### 4.2.3 마지막 달 (계약 해지)

퇴거일 당일까지 임차인이 부담한다. 퇴거 당일에 이사하는 사례가 많기 때문이다.

해지일은 사전에 확정되므로 **청구서 발행 시점에 일할을 반영한다.**
해지일이 입력된 계약은 고정액 항목(임대료·고정관리비)을 시스템이 자동으로 일할 계산한다.
정산 항목은 담당자가 직접 입력한다. → 4.2.5

| 경우 | 처리 |
|---|---|
| 해지일이 당월 청구일 이후 | 당월 청구서에 일할을 반영해 발행 |
| 해지일이 당월 청구일 이전 | 당월 청구서를 발행하지 않음. 일할분은 **퇴거 정산 청구서**로 생성해 보증금에서 차감 |
| 청구서 발행 후 해지 확정 | 발행된 청구서는 변경하지 않음. 차액은 퇴거 정산에서 보증금 환급액에 가감 |

```
임대료 7,000,000원 · 청구일 당월 19일

① 해지일 10/25   10/19 발행 청구서에 일할 반영
                 7,000,000 × 25 ÷ 31 = 5,645,161원

② 해지일 10/5    10월 청구서 미발행. 9월분까지 정상 청구
                 5일분 7,000,000 × 5 ÷ 31 = 1,129,032원 → 퇴거 정산 청구서
```

**퇴거 정산 청구서의 원장 처리**

```
청구            일할분 (매출채권 차변)
수납            결제수단 '보증금상계' (매출채권 대변)
보증금 차감     동일 금액 (임대보증금 차변)
보증금 환급     잔여 보증금 (임대보증금 차변)
```

퇴거 정산 청구서는 CTR-3 해지 처리 과정에서 생성한다. 임차인 발송은 선택 사항이다.
보증금에서 차감하더라도 임대료 수익과 세금계산서의 근거가 원장에 남아야 하므로 청구서를 생성한다.

### 4.2.4 청구일 경과 후 계약 시작

계약이 시작된 회차의 청구일이 이미 경과한 경우, 다음 회차 청구일에 **청구서를 2장 발행**한다.

```
계약시작일 2026-08-29 · 청구일 당월 19일 · 납부마감일 당월 말일

8/19  이미 경과. 8월분 미발행
9/19  청구서 2장 발행
        ① 8월분 일할   8/29~8/31 = 3일   7,000,000 × 3 ÷ 31 = 677,419원
        ② 9월분 전액   9/1~9/30          7,000,000원
      납부마감일은 둘 다 9/30
```

합산하지 않는 이유는 어느 월의 요금인지 구분되어야 하기 때문이다.

### 4.2.5 정산 항목의 부분 기간

정산 항목(전기·수도 등)은 고지서의 부과 기간으로 일할한다. 달력 월이 아니라 고지서 부과 기간이 기준이다.
자동으로 적용하지 않고, 담당자가 관리비 정산의 일할 계산기로 계산값을 보고 적용한다 → 4.1.9 · PAY-10

### 4.2.6 단수 처리 — 미확정 → 4.7

> 아래는 검토 중인 안이다. 검산 예시(4.3·4.4)는 단수 처리를 적용하지 않은 금액이다.

| 단계 | 규칙 |
|---|---|
| 항목별 금액 | 안분·일할 산출 결과는 **원 미만 절사** |
| **청구서 합계** | **100원 미만 자동 절사** |
| 공급가액·부가세 | 절사 후 합계에서 역산. 공급가액 = 합계 ÷ 1.1 (원 미만 절사), 부가세 = 합계 − 공급가액 |

**시스템 도입 후 발행하는 청구서부터 적용한다.** 현재 청구서는 원 단위까지 청구하고 있으므로
도입 시 임차인에게 안내한다.

청구서 합계의 절사액은 **청구서 내 우선순위가 가장 낮은 항목의 금액에서 차감**하고,
해당 청구 건에 절사액을 기록한다. 청구서에는 `단수 절사` 행으로 표시한다.

```
임대료          7,700,000
고정관리비      1,980,000
전기요금          682,347   → 절사 후 682,300 으로 청구 (절사액 47 기록)
단수 절사             −47   ← 청구서 표시용 행
──────────────────────────
합계           10,362,300      (절사 전 10,362,347)
```

절사액을 별도의 음수 청구 건으로 두지 않는다. 임차인이 청구서 합계를 입금했을 때
항목별 배분 합계와 일치해야 완납으로 처리되기 때문이다.

정산 항목의 원 미만 절사 잔차는 부담 비율이 가장 큰 유닛에 더한다 → 4.1.8
본 절의 100원 미만 절사는 그 뒤 청구서 합계 단계에서 적용한다.

### 4.2.7 약정액이 바뀌는 달 (임대료 인상 예약)

- 임대료 인상 예약의 적용일부터 새 금액을 **자동으로** 쓴다 → CTR-2 · CTR-3
- 적용일이 1일이면 그 달 청구서부터 새 금액 그대로다
- 적용일이 달 중간이면 그 달은 **전 금액 × 적용일 전 일수 + 새 금액 × 적용일부터 일수**를 그 달 일수로 나눠 합한다. 각 부분은 원 미만 절사

```
임대료 3,300,000 → 3,465,000 (부가세 포함) · 적용일 2028-11-16 · 11월 30일

전   3,300,000 × 15 ÷ 30 = 1,650,000
후   3,465,000 × 15 ÷ 30 = 1,732,500
11월 임대료                 3,382,500
```

## 4.3 수납 배분

### 4.3.1 배분 순서

입금 1건을 청구 여러 건에 배분하는 순서다.

```
① 전월 미납액(마감한 달에서 넘어온 돈)   언제나 먼저다 → 4.3.6
② 마감하지 않은 달은 오래된 청구년월부터
③ 같은 회차 안에서는 우선순위가 낮은 번호부터    건물별 설정 → PRO-3
④ 같은 우선순위면 계약 순서            한 사업자가 같은 건물에 계약이 여럿일 때 → PAY-13
```

- **마감한 달의 청구에는 배분하지 않는다.** 그 달의 남은 돈은 전월 미납액으로 넘어갔기 때문이다. 기준은 입금일이다
- **입금일에 아직 발행하지 않은 청구에도 배분하지 않는다.** 청구서를 받기 전에 들어온 돈이 그 청구를 채우지 않는다

- 대납 항목은 그 청구항목의 우선순위를 따르며, 같은 우선순위 안에서 자기 몫 다음이다 → 4.1.7-3
- 추가 청구는 우선순위 99로 둔다(연체료와 같다). 미확정 → 4.7

**입금액과 청구액이 같은지를 따지지 않는다.** 전액을 냈다면 이 순서로 채워도 결과가 같고,
모자라면 남는 것이 미납이다.

> **⚠️ 이번 달 청구서와 금액이 똑같이 들어와도 미납액부터 채운다.**
> 임차인이 이번 달 청구서만 보고 냈더라도 지난 미납이 먼저 해결되어야 한다.
> 그 결과 이번 달 청구에 미납이 남고, 그 미납에 연체료가 쌓인다. 의도된 동작이다 → 4.3.3

- 임차인이 관리비만 먼저 입금해도 임대료부터 채운다. 항목별 납부상태는 달라지지만
  계약의 미납 합계는 같다
- 입금은 **입금일시 순서로** 처리한다. 앞 입금의 배분이 뒤 입금이 채울 청구를 줄인다
- 확정 전에 배분 미리보기로 확인한다. 확정 후에는 배분 재조정으로 고친다 → PAY-13, PAY-9

### 4.3.2 검산 예시 — 부분납

```
청구 (2026년 9월분, 부가세 포함)
  임대료       7,700,000   우선순위 1
  고정관리비   1,980,000   우선순위 2
  주차비         330,000   우선순위 3
  합계        10,010,000

입금 8,000,000원
```

| 청구항목 | 청구액 | 배분액 | 미납액 | 납부상태 |
|---|---|---|---|---|
| 임대료 | 7,700,000 | 7,700,000 | 0 | 완납 |
| 고정관리비 | 1,980,000 | 300,000 | 1,680,000 | 부분납 |
| 주차비 | 330,000 | 0 | 330,000 | 납부전 |
| 합계 | 10,010,000 | **8,000,000** | 2,010,000 | |

```
본관302호  전월 미납액  7월 마감 때 넘어온 7월분 미납                                     = 957,511
                        (전기요금 580,807 · 수도요금 181,043 · 수도요금(본관301호 대납) 181,043

|---|---|---|---|---|---|

(표의 납부상태는 납부마감일 전 기준이다. 마감일이 지나면 수납 0인 청구는 `미납`이 된다 → 3.2)

### 4.3.4 과납

**과납은 임차인에게 돌려줄 돈이다.** 계약의 매출채권 잔액이 0보다 작으면 그만큼이 과납이다.
별도 계정을 두지 않는다.

```
입금이 미납보다 많다    입금 11,000,000 − 배분 10,010,000            = 과납 990,000
이미 낸 청구를 감액     본관1층 7월 수도요금 1,337,087 → 1,319,087
                       (감액 18,000 · 7월분은 07.31에 완납)          = 과납 18,000
```

| 규칙 | 내용 |
|---|---|
| 귀속 계약 | 입금이 남으면 그 입금이 마지막으로 배분된 계약. 배분할 청구가 없었으면 그 임차인의 계약이 하나면 그 계약, 여럿이면 담당자가 고른다(목업은 첫 계약). 감액이면 감액한 청구의 계약 |
| 미납 먼저 | 과납이 생길 때 그 계약에 미납이 있으면 **미납부터 채운다**(배분 순서는 4.3.1). 남는 금액만 과납이다 |
| 원장 | 입금이 남으면 남는 금액을 그 계약의 `수납`(청구 건 없음)으로 기록한다. 감액은 `감액` 한 줄이다. 청구 건에 수납이 넘치면 넘친 만큼 수납 배분을 과납으로 돌린다(원장 거래는 없다). 청구 건은 `완납` 그대로다 |
| 이월 | **따로 처리하지 않는다.** 마감 때 전월 과납액으로 다음 달에 넘어간다 → 4.3.6 |

| 쓰임 | 원장 기록 |
|---|---|
| 다음 청구 | 청구서를 발행할 때 새 청구 건에 **자동으로 먼저 배분한다. 우선순위가 낮은 항목부터 채운다**(임차인이 낸 돈이 임대료처럼 큰 항목에 그대로 맞도록). 수납 배분만 옮기고 원장 거래는 만들지 않는다. 청구서에는 합계 밖에 `−금액`으로 표기 |
| 환불 | 계약 원장(CTR-3)의 `환불`로 기록한다. **과납 잔액까지만** 돌려줄 수 있고 일부만 돌려줘도 된다. 환불계좌 위치는 미확정 → 4.7 |

- 과납은 청구 합계와 세금계산서에 넣지 않는다. 돈만 오가는 일이라 매출이 바뀌지 않는다
- 감액은 매출이 줄어드는 일이다. 세금계산서 항목의 감액은 수정세금계산서 대상일 수 있다 → 4.7
- 지난 회차를 **더 받아야 하면** 감액의 반대가 아니라 추가 청구로 넣는다. 지난 청구를 늘리면 지난 납부마감일 기준으로 연체료가 붙기 때문이다 → CTR-3
- **과납액은 어느 청구항목의 돈도 아니다.** 입금은 우선순위대로 배분되므로, 남은 돈이 수도요금 몫인지 전기요금 몫인지 정할 수 없다.
  그래서 청구 건에 붙이지 않고 `과납액` 한 줄로 따로 보인다(PAY-6 · PAY-13). 그 달의 납부상태는 `과납`이다 → 3.2
- 미납은 다르다. 청구는 항목마다 있고 배분 순서가 정해져 있어 어느 항목이 덜 채워졌는지 분명하다. 미납은 항목별로 둔다

### 4.3.5 오납

**오납은 낼 의무가 없는 돈이 잘못 들어온 입금이다.** 예: 다른 건물 임차인이 이 계좌로 보낸 돈, 계좌번호를 잘못 넣은 남의 송금.

- 입금 매칭(PAY-13)에서 `오납`으로 표시한다. 임차인 입금이 아니고 돌려줄 필요도 없으면 `무시`다
- 계약에 속하지 않으므로 원장에 기록하지 않는다. 입금 기록에 환불일·환불계좌·처리자를 남긴다
- 처리는 환불뿐이다. 입금 매칭(PAY-13)에서 그 입금에 환불일·환불계좌를 기록한다

선납은 정책적으로 받지 않으므로 선불임대료 계정을 두지 않는다.
전월에 미리 수령하는 임대료는 해당 월의 임대료이며 별도 개념이 아니다.

### 4.3.6 전월 잔액 이월 (미납·과납)

**월 마감을 하면 계약마다 남은 잔액을 한 줄로 다음 달에 넘긴다.** 받을 돈이면 `전월 미납액`, 돌려줄 돈이면 `전월 과납액`이다. 한국 관리비 고지서의 「전월 미납액」 그대로다.

```
비씨에이전시   6월분 청구 5,054,474 · 6월 중 수납 0
  07.03 6월 마감   → 전월 미납액 5,054,474 (6월분은 `미납`으로 굳는다)
  07.31 입금 5,000,000 → 전월 미납액부터 줄인다 → 전월 미납액 54,474 · 7월분 청구 5,091,998은 그대로
  08.05 7월 마감   → 미납액 54,474 + 7월분 5,091,998 = 전월 미납액 5,146,472
```

| 규칙 | 내용 |
|---|---|
| 청구가 아니다 | 이미 청구하고 세금계산서를 발행한 돈이다. 청구 합계와 세금계산서에 넣지 않고 청구서에 별도 안내로 적는다(PAY-1) |
| 원장 | **원장 거래를 만들지 않는다.** 잔액이 그대로이기 때문이다. 이월은 전월 잔액 이월 데이터로 남고, 그 뒤 들어온 수납이 원장에 `전월 미납액`으로 적힌다 |
| 마감한 달 | 청구·수납·납부상태가 그 뒤로 바뀌지 않는다. 월 마감 보고서도 다시 뽑아도 같다 |
| 배분 | 전월 미납액이 언제나 먼저다 → 4.3.1 |
| 다음 마감 | 남은 전월 미납액과 그 달 미납을 합쳐 다시 한 줄로 넘긴다 |
| 연체료 | 전월 미납액 안에 **생긴 달별 금액을 남겨 둔다.** 연체료는 원래 납부마감일부터 센다. 전월 미납액에 들어온 돈은 오래된 달 몫부터 줄인다 → 4.4 |
| 마감 취소 | 전월 미납액에 수납이 배분된 뒤에는 그 달 마감을 취소할 수 없다 → PAY-11 |

- 우선순위는 마감 전에 일부만 냈을 때 그 달 안에서 어느 항목부터 채울지 정할 때만 쓰인다
- 과납도 같은 방식으로 넘어간다. 마감 때 계약 잔액이 0보다 작으면 `전월 과납액`이다. 한 계약에 전월 미납액과 전월 과납액이 함께 생기지 않는다(미납을 먼저 채우므로)
- **마감한 달 청구를 나중에 감액하면** 그 달은 바뀌지 않고, 다음 달로 넘어간 전월 잔액이 그만큼 줄어든다. 받을 돈이 없었으면 전월 과납액이 된다

## 4.4 연체료

### 4.4.1 산출식

**연체료는 구간별로 계산해 합한다.** 납부마감일 다음날부터 오늘까지를 **수납이 들어올 때마다 끊고**,
구간마다 그 동안 남아 있던 미납액에 이율과 일수를 곱한다.

```
연체료 = Σ 구간 ( 구간 동안의 미납액 × 연체이자율 × 구간 일수 ÷ 365 )    구간마다 원 미만 절사
```

| 항목 | 값 |
|---|---|
| 연체이자율 | **계약마다 다르다.** 계약 등록 시 입력한다(CTR-2). 기본 연 8% |
| 구간 | 납부마감일 다음날부터 시작해 수납일마다 끊는다. 마지막 구간은 오늘까지 |
| 구간 동안의 미납액 | **부가세를 포함한** 그 청구의 미납액. 수납이 들어오면 다음 구간부터 줄어든다 |
| 절사 | 구간마다 원 미만 절사 후 합한다. **내역서의 각 줄과 합계가 맞아야 한다** |

> **⚠️ 지금 남은 미납액에 전체 연체일수를 곱하지 않는다.**
> 중간에 일부를 낸 청구는 낸 날까지 더 큰 금액이 밀려 있었다. 남은 금액만 곱하면 연체료가 크게 줄어든다.
> 아래 예시 3에서 이렇게 계산하면 734원이지만 실제로는 51,693원이다.

- **청구 건 단위로 계산하고 달(청구서)별로 합한다.** 같은 달 청구 건들은 납부마감일이 같다
- **연체료에는 연체료를 붙이지 않는다**
- **전월 미납액으로 넘어가도 원래 납부마감일부터 센다.** 전월 미납액에 들어온 돈은 오래된 달 몫부터 줄인다 → 4.3.6
- **늦게라도 다 낸 청구에도 연체료가 남는다.** 미납액이 0이 되어도 연체료는 남는다. **연체료도 미납이다**(계약서에 정한 돈). PAY-2에 그대로 올라온다
- **연체료 정리일까지의 구간은 다시 계산하지 않는다.** 정리일에 걸친 구간은 정리일부터 다시 센다 → 4.4.3

### 4.4.2 검산 예시

**예시 1 — 구간이 하나**

```
미납액 1,680,000원 · 연체이자율 8% · 연체일수 12일 · 그 사이 수납 없음

연체료 = 1,680,000 × 0.08 × 12 ÷ 365 = 4,418.63 → 4,418원
```

**예시 2 — 늦게 다 낸 청구** (주식회사루비뮤직 6월분, 연 8%)

```
6월분 미납 385,000원 · 납부마감일 6/30 · 7/3 6월 마감(전월 미납액으로 이월) · 7/31에 전액 입금

6/30 ~ 7/31   31일   385,000 × 8% × 31 ÷ 365 = 2,615원
미납액은 0이지만 연체료 2,615원이 남는다
```

**예시 3 — 중간에 일부를 낸 청구** ((주)비씨에이전시 6월분, 연 12%, 오늘 8/10)

```
6월분 청구 5,054,474원 · 납부마감일 6/30 · 7/3 6월 마감(전월 미납액으로 이월) · 7/31에 5,000,000원 입금

6/30 ~ 7/31   31일   5,054,474 × 12% × 31 ÷ 365 = 51,514원
7/31 ~ 8/10   10일      54,474 × 12% × 10 ÷ 365 =    179원
합계                                              51,693원
```

### 4.4.3 청구 처리

- 연체료는 **표시만 하며 자동으로 청구하지 않는다.** PAY-2와 미납 안내 메일에 예상액으로 보인다
- **수납 처리(PAY-2)에서 정리한다.** 처리 방식은 다섯 가지다

| 처리 | 연체료 | 비고 |
|---|---|---|
| 이번엔 안 함 | — | 정리하지 않는다. 원장에 오르지 않고 계속 쌓인다 |
| 전액 받기 | 받은 날까지의 연체료 전부 | |
| 50% 감면 | 절반 (원 미만 절사) | 실무에서 가장 흔한 감면 |
| 직접 입력 | 관리자가 입력 | **낮출 수만 있다.** 높일 수는 없다 |
| 전액 감면 | 0원 | 청구 건 없이 정리일만 기록한다 |

- 기본값: 청구 미납이 있는 계약은 `이번엔 안 함`, **연체료만 남은 계약은 `전액 받기`**
- 늦게 낸 기간이 짧으면 없애 주거나 절반 이상 줄여 주는 것이 실무다. 얼마나 줄일지는 관리자가 정한다
- 받기로 한 연체료는 받은 날 `연체료` **청구 한 건**으로 원장에 기록하고 같은 수납으로 채운다. 정기 청구서와 별개이며 배분 우선순위는 99로 가장 마지막이다
- 받은 금액이 합계(미납 + 연체료)보다 적으면 연체료 청구가 미납으로 남는다
- 낮춘 차액은 **감면**이다. 원장 금액에는 없고, 받은 날 기록하는 연체료 청구의 내용에 산정액과 감면액을 적는다
- 받은 날이 그 계약의 **연체료 정리일**이 된다. 그날까지의 연체료는 받았든 감면했든 다시 세지 않는다
- 퇴거를 앞둔 임차인이 보증금을 더 돌려받으려고 연체료 감면을 요청하는 일이 많다. 감면 여부와 금액은 관리자가 정한다
- **산출된 연체료는 부가세 포함 금액이다.** 기준 금액(미납액)이 부가세 포함이므로 산출액도 부가세 포함으로 본다. 별도로 부가세를 가산하지 않는다
- 연체료는 과세 항목이므로 공급가액과 부가세는 역산해 기록한다

```
연체료(합계) 4,418원  →  공급가액 4,418 ÷ 1.1 = 4,016원 · 부가세 402원
```

```
예) 비씨에이전시 · 8/10 현금 수납 · 산정 연체료 68,433원(6월 51,693 · 7월 16,740) 중 55,000원만 받음(직접 입력)
    50% 감면이면 34,216원을 받고 34,217원을 감면한다
    청구  연체료 (08.10까지 · 68,433원 중 13,433원 감면)   55,000원  (공급가액 50,000 · 부가세 5,000)
    8/10까지의 연체료는 정리됨. 이후 미납이 남으면 8/10 다음날부터 다시 센다
```

며칠 경과한 건은 실무상 청구하지 않는 경우가 많다.
자동 청구 시 임차인과의 관계가 악화되므로 판단을 관리자에게 맡긴다.

## 4.5 공실률

```
공실률 = 공실 유닛 수 ÷ (전체 유닛 수 − 비운영중 유닛 수)
```

| 유닛상태 | 분자 | 분모 |
|---|---|---|
| 공실 | 포함 | 포함 |
| 사용중 | 제외 | 포함 |
| 비운영중 | 제외 | **제외** |

비운영중은 임대 대상이 아니므로 분모에서 제외한다.
건물주 직접 사용과 공사 중 두 경우다. → 3.2

준비중 계약이 있는 유닛은 **공실로 집계**한다. 임대료가 발생하지 않는 상태이기 때문이다.
계약이 확보된 사실은 유닛 목록의 임차인명으로 확인한다.

## 4.6 은행 거래내역 매칭

### 4.6.1 처리 절차

```
① 파일 업로드 및 건물 선택
     건물마다 납부 계좌가 다르므로 매칭 대상을 해당 건물의 계약으로 한정
② 컬럼 매핑                 거래일시 / 거래구분 / 입금자명 / 입금액
     은행별로 저장해 재사용
③ 입금 건 추출               입금액 > 0 인 행만. 수수료 등 출금 행 제외
④ 입금자명 정규화
⑤ 매칭
⑥ 관리자 승인 → 원장 기록
```

**파일 해석 규칙** — 은행에서 내려받은 파일을 그대로 올린다. 담당자가 손질하지 않는다.
- **앞부분 머리말 행**(건물명·조회기간 등)을 건너뛴다. `거래일시`와 `입금`이 함께 있는 행을 머리글로 본다
- 열은 위치가 아니라 **이름으로** 찾는다. 은행마다 이름이 다르다(예: 입금자명이 `기재내용`, 거래구분이 `적요`).
  찾은 결과를 은행별로 저장한다
- 금액의 **천 단위 쉼표를 제거**한다. 입금란이 0인 행은 출금이다
- **전각 문자를 반각으로** 바꾼다(`ＰＣ뱅킹` → `PC뱅킹`)
- `거래구분`은 표시만 한다. `대체입금`도 임차인 입금일 수 있어 자동 제외 근거로 쓰지 않는다

### 4.6.2 입금자명 정규화

비교 전 다음을 제거한다.

```
공백
법인격 표기   (주)  ㈜  주식회사  (유)  ㈲  유한회사
```

### 4.6.3 매칭 규칙

**자동 매칭은 임차인(사업자)에 등록된 입금자명 별칭과 일치하는 경우에만 수행한다.**
별칭은 사업자 단위로 등록한다. 은행에 표기되는 입금자명은 계약이 아닌 사업자의 속성이며,
사업자 단위로 두면 재계약·추가 계약 시에도 매칭이 유지된다.

| 결과 | 조건 | 처리 |
|---|---|---|
| 자동 매칭 | 별칭 일치 | 선택한 건물에 있는 그 사업자의 모든 계약 청구에 배분 → 4.3 |
| 미매칭 | 등록된 별칭 없음 | 관리자가 임차인을 고른다. 정규화한 상호와 같거나, 앞 4자 이상이 같은 임차인이 하나뿐이면 선택란에 미리 채운다(참고) |

미매칭 건을 수동 지정할 때 해당 입금자명을 **별칭으로 등록할지 묻는다.**
등록 후에는 자동으로 매칭되므로 운용 기간이 길어질수록 자동화율이 상승한다.
**첫 달에는 등록된 별칭이 없어 모든 입금을 담당자가 지정한다.** 상호와 똑같은 입금자명도 마찬가지다.

임차인 입금이 아닌 입금(반환·환불, 임차인이 아닌 거래처)은 담당자가 `무시`로 표시한다. 돌려줘야 하는 입금은 `오납`이다 → PAY-13 · 4.3.5

### 4.6.4 별칭 기반 식별을 채택한 이유

실제 은행 거래내역의 입금자명은 상호와 일치하지 않는다.

| 실제 표기 | 문제 |
|---|---|
| `(주)케이더블유인터` | 적요 길이 제한으로 상호 절단 |
| `ICB` | 영문 약어 |
| `AMADEUS KO` | 영문 약어 + 절단 |
| `유한회사 고우컴퍼니` | 법인격 표기 방식 상이 |

상호 대조로는 식별할 수 없으며, 명칭 유사도로 자동 매칭하면 다른 계약에 입금이 기록된다.

### 4.6.5 다건 입금 처리

동일 입금자명의 입금이 여러 건이면 **입금일시 순서로 하나씩** 배분한다. 묶지 않는다.
입금 1건이 통장 1행이므로 따로 기록해야 통장과 대조할 수 있다.

```
예) 에스씨케이컴퍼니 13,200,000   13:05:36   → 임대료 13,200,000 (우선순위 1)
    에스씨케이컴퍼니  7,549,294   13:05:37   → 나머지 항목 전부
```

임대료와 관리비를 나눠 낸 경우에도 우선순위 순서로 채우면 각 입금이 제 항목에 들어간다.

### 4.6.6 승인 절차

자동 매칭 결과는 **관리자 승인 후에만** 원장에 기록한다.
매칭 오류 시 다른 계약에 입금이 기록되며, 원장은 사후 정정이 어렵다.

| 추가 청구의 배분 우선순위 | 지금은 99(연체료와 같음). 다른 번호로 둘지 대표가 결정 → 4.3.1 |
| 단수 처리 적용 여부 | 4.2.6(청구서 합계 100원 미만 절사)은 목업에 없다. 유지하면 목업과 6·7월 은행 입금액을 다시 맞춘다 |
| 감액의 수정세금계산서 | 세금계산서 항목을 감액하면 수정세금계산서를 발행해야 하는지 세무사 확인 후 결정 → CTR-3 |
| 계약별 청구일 변경 위치 | 3.5는 청구일을 계약에서 덮어쓸 수 있다고 하나 CTR-2·CTR-3 목업에 고치는 곳이 없다. 둘지, 둔다면 CTR-3 요약 임대정보 수정에 둘지 결정. 납부마감일은 건물 설정으로 정했다 |
| 화면의 「정산 항목」 표기 | 3.2-2는 화면에 `청구항목`만 쓴다고 하나 CTR-3 대납 카드에 「정산 항목(전기·수도 등)」이 보인다. 허용할지 결정 |
| 현장 수납의 정정 진입 경로 | PAY-9는 PAY-13에서만 들어간다. 현금·카드·보증금상계 수납을 무효 처리할 입구(PAY-2 또는 CTR-3 원장)를 둘지 결정 |
| 환불계좌 위치 | 환불계좌는 계약자 정보에만 있고, 그 칸은 「임차인과 계약자가 다름」일 때만 보인다. 대부분의 계약은 넣을 곳이 없다. 임차인(사업자) 정보에 둘지 결정 → CTR-2 · 4.3.4 |
| 계약 해지·삭제·웰컴 재전송 버튼 위치 | 계약 상세 위쪽 버튼을 「목록」만 남기면서 자리가 없어졌다. 요약 탭 계약정보 카드에 둘지 결정 → CTR-3 |
| 연체료 전액 감면 금액 기록 | 지금은 정리일만 남아 감면액의 흔적이 없다. 금액을 기록할지 결정 |
| 납부 계좌가 둘일 때 | 임대료·관리비 납부 계좌가 다르면 ① 청구서에 계좌를 어떻게 안내할지(항목별 / 합계 둘로 나눔) ② 관리비 계좌로 들어온 돈을 임대료에 배분해도 되는지(지금 배분 규칙은 계좌를 보지 않는다) ③ 은행 거래내역을 계좌마다 올리는지 결정 → PRO-3 · PAY-13 · 4.3.1 |
