# 4. 계산 규칙

본 장은 금액을 산출하는 규칙을 정의한다.
**오구현 시 금액이 틀어지는 부분이므로 예시 검산을 함께 제시한다.**
구현 후 본 장의 예시로 검증한다.

---

## 4.1 공용 관리비 안분

### 4.1.1 개념

상업용 관리비는 정액이 아니라 **건물 단위 고지서를 유닛에 배분한 결과**다.
단일 계약 정보만으로 금액을 산출할 수 없으며, 동일 건물 내 타 유닛의 면적과 검침값이 필요하다.

| 용어 | 정의 |
|---|---|
| 고지서 총사용량 | 한국전력·상수도사업본부 등이 청구한 건물 전체 사용량 |
| 검침 사용량 | 유닛별 계량기 값의 당월 − 전월 차이. **원본이며 수정하지 않는다** |
| 조정 배수 | 계량기 편차 보정 등에 사용. 기본값 1.0. 별도 기록으로 관리 |
| 정산 사용량 | 검침 사용량 × 조정 배수 |
| 잔여 사용량 | 고지서 총사용량 − Σ 정산 사용량. 공용부에 해당 |

### 4.1.2 산정 규칙

```
1) 검침 사용량   = 당월 검침값 − 전월 검침값              계량기 보유 유닛만
2) 정산 사용량   = 검침 사용량 × 조정 배수
3) 잔여 사용량   = 고지서 총사용량 − Σ 정산 사용량
                   (검침분 미청구 건물은 고지서가 이미 공용분이므로 잔여 = 총사용량)
4) 배분 가중치
      배분 기준 = 사용량  →  가중치 = 정산 사용량
      배분 기준 = 면적    →  가중치 = 임대면적 × 조정 배수
5) 잔여 배분     = 잔여 사용량 × (가중치 ÷ Σ가중치)        부담 대상 유닛만
6) 유닛 총사용량 = 정산 사용량(청구 대상인 경우) + 잔여 배분
7) 유닛 청구금액 = 고지서 총금액 × (유닛 총사용량 ÷ 고지서 총사용량)
8) 전력기금·TV수신료도 7)과 동일한 비율로 환산
```

> **⚠️ 4단계에서 조정 배수를 중복 적용하지 않는다.**
> 배분 기준이 `사용량`일 때 정산 사용량에는 이미 배수가 반영되어 있다. 다시 곱하면 이중 적용된다.
> 배분 기준이 `면적`일 때만 면적에 배수를 곱한다.

### 4.1.3 건물·항목별 설정

배분 방식은 건물마다 다르다. 건물 상세 청구설정탭(PRO-3)에서 항목별로 설정한다.

| 설정 | 선택지 | 의미 |
|---|---|---|
| 검침분 청구 여부 | 청구함 / 임차인 직접 납부 | 직접 납부 시 고지서가 공용분만 발행됨 |
| 잔여분 부담 대상 | 자동 / 전체 유닛 / 검침기 없는 유닛만 | — |
| 잔여분 배분 기준 | 자동 / 사용량 비율 / 임대면적 비율 | — |

`자동`은 다음 규칙을 따른다.

```
검침기 없는 유닛 없음  →  잔여는 순수 공용분. 전체 유닛에 사용량 비율로 배분
검침기 없는 유닛 있음  →  잔여를 검침기 없는 유닛에 임대면적 비율로 배분
```

### 4.1.4 검산 예시 1 — 전기 (건물 일괄, 전 유닛 계량기)

```
고지서      10,000 kWh / 5,000,000원
유닛        A 검침 3,000   B 검침 2,000   C 검침 1,000
조정 배수   A 1.0   B 1.0   C 2.0          ← C는 1층 상가, 계량기 편차 보정
설정        검침분 청구함 / 부담 대상 전체 / 배분 기준 사용량
```

| 단계 | A | B | C | 합계 |
|---|---|---|---|---|
| 2) 정산 사용량 | 3,000 | 2,000 | **2,000** | 7,000 |
| 3) 잔여 사용량 | | | | **3,000** |
| 4) 가중치 | 3,000 | 2,000 | 2,000 | 7,000 |
| 5) 잔여 배분 | 1,285.7 | 857.1 | 857.1 | 3,000 ✓ |
| 6) 유닛 총사용량 | 4,285.7 | 2,857.1 | 2,857.1 | **10,000** ✓ |
| 7) 청구금액 | 2,142,857 | 1,428,571 | 1,428,571 | **5,000,000** ✓ |

조정 배수는 전용부 청구액과 공용 배분 비율에 모두 반영된다.
C가 더 부담한 만큼 A·B가 덜 부담하며, 총액은 고지서와 일치한다.

### 4.1.5 검산 예시 2 — 전기 (공용부만, 임차인 직접 납부)

전용부는 임차인이 한국전력에 직접 납부하고, 건물은 공용분 고지서만 수령하는 경우다.
유닛 검침은 수행하되 **배분 비율 산출에만 사용**한다.

```
고지서      3,000 kWh / 1,500,000원       ← 이미 공용분
유닛 검침   A 3,000   B 2,000   C 1,000 (배수 2.0)
설정        검침분 임차인 직접 납부 / 부담 대상 전체 / 배분 기준 사용량
```

| 단계 | A | B | C | 합계 |
|---|---|---|---|---|
| 2) 정산 사용량 | 3,000 | 2,000 | 2,000 | 7,000 |
| 3) 잔여 사용량 | | | | **3,000** (총사용량 그대로) |
| 5) 잔여 배분 | 1,285.7 | 857.1 | 857.1 | 3,000 ✓ |
| 6) 유닛 총사용량 | 1,285.7 | 857.1 | 857.1 | 3,000 ✓ |
| 7) 청구금액 | 642,857 | 428,571 | 428,571 | **1,500,000** ✓ |

검침분을 청구하지 않으므로 6단계에서 정산 사용량을 더하지 않는다.

### 4.1.6 검산 예시 3 — 상하수도 (일부 유닛만 계량기)

```
고지서      1,000 톤 / 2,000,000원
1층 카페    계량기 있음. 검침 300톤. 임대면적 100㎡. 조정 배수 1.2  ← 계량기 편차 보정
2층         계량기 없음. 임대면적 200㎡
3층         계량기 없음. 임대면적 300㎡
설정        검침분 청구함 / 부담 대상 검침기 없는 유닛만 / 배분 기준 면적
```

| 단계 | 1층 | 2층 | 3층 | 합계 |
|---|---|---|---|---|
| 2) 정산 사용량 | **360** (300×1.2) | — | — | 360 |
| 3) 잔여 사용량 | | | | **640** |
| 4) 가중치 (면적×배수) | 부담 대상 아님 | 200 | 300 | 500 |
| 5) 잔여 배분 | — | 256 | 384 | 640 ✓ |
| 6) 유닛 총사용량 | 360 | 256 | 384 | **1,000** ✓ |
| 7) 청구금액 | 720,000 | 512,000 | 768,000 | **2,000,000** ✓ |

1층의 조정 배수를 올리면 잔여가 줄어 2·3층 부담이 감소한다. 총액은 항상 고지서와 일치한다.

### 4.1.7 공실 유닛 처리

공실 유닛도 공용분 안분 대상에 포함하되 **청구서를 생성하지 않는다.**
해당 금액은 건축주가 부담하며 임차인에게 전가하지 않는다.

공실을 안분에서 제외하면 공실이 늘수록 남은 임차인의 관리비가 상승해 분쟁 소지가 된다.

**배분 기준이 사용량인 경우 공실 유닛의 검침 사용량은 0에 가까우므로,
공실 몫을 별도로 산정한 뒤 잔여를 임차 유닛에 배분한다.**

```
5-1) 공실 부담분 = 잔여 사용량 × (공실 유닛 임대면적 ÷ 전체 임대면적)
5-2) 임차 유닛 배분 대상 = 잔여 사용량 − 공실 부담분
5-3) 임차 유닛 배분 = 배분 대상 × (가중치 ÷ Σ가중치)
```

검산 (예시 1에서 D호가 공실, 임대면적 비중 20%인 경우)

```
잔여 사용량            3,000
공실 부담분            3,000 × 20% = 600        → 건축주 부담. 청구서 미생성
임차 유닛 배분 대상    2,400
  A 2,400 × 3/7 = 1,028.6   B 685.7   C 685.7   합 2,400 ✓

검증  임차 전용부 7,000 + 임차 공용배분 2,400 + 공실분 600 = 10,000 ✓
```

> **⚠️ 확인 필요**
> 배분 기준이 사용량인 경우의 공실 몫 산정을 위 방식(면적 비중)으로 확정할지 검토가 필요하다.
> 사용량 기준으로만 배분하면 공실 가중치가 0이 되어 공용분 전액이 임차인에게 귀속된다.

### 4.1.8 검증 규칙

정산 확정 시 항목별로 다음을 검증한다. 불일치 시 확정할 수 없다.

```
임차인 청구액 합계 + 공실·미청구분 = 고지서 총금액
```

산출 결과에 `공실·미청구분`을 별도 행으로 표시해 건축주 부담액을 확인할 수 있게 한다.

### 4.1.9 산정 기간

전기·수도의 산정 기간은 달력 월과 어긋나는 경우가 많다(예: 매월 10일~익월 9일).
**본 시스템은 산정 기간을 관리하지 않는다.** 담당자가 고지서 기준으로 금액을 입력한다.

입주·퇴거로 기간이 일부만 해당하는 유닛은 담당자가 직접 계산해 금액을 덮어쓰고 사유를 기록한다.
시스템은 검침과 안분까지만 자동 처리한다.

## 4.2 일할 계산

### 4.2.1 원칙

해당 기간의 **실일수**를 기준으로 한다. **시작일과 퇴거일을 모두 포함**한다.

```
청구액 = 월 약정액 × 청구 대상 일수 ÷ 해당 기간 총일수
```

30일 고정 방식을 사용하지 않는다. 달마다 초과 징수되어 연간 합계가 어긋나기 때문이다.

### 4.2.2 첫 달

```
임대료 7,000,000원 · 계약시작일 2026-08-13

대상 기간   8/13 ~ 8/31 = 19일     (시작일 포함)
총일수      8월 = 31일
청구액      7,000,000 × 19 ÷ 31 = 4,290,322.58 → 4,290,322원
```

### 4.2.3 마지막 달

```
임대료 7,000,000원 · 퇴거일 2026-07-31

대상 기간   7/1 ~ 7/31 = 31일      (퇴거일 포함)
청구액      전액 7,000,000원
```

퇴거일 당일까지 임차인이 부담한다. 퇴거 당일에 이사하는 사례가 많기 때문이다.

### 4.2.4 청구일 경과 후 계약 시작

계약이 시작된 회차의 청구일이 이미 경과한 경우, 다음 회차 청구일에 **청구서를 2장 발행**한다.

```
계약시작일 2026-08-29 · 청구일 매월 19일 · 납부마감일 매월 말일

8/19  이미 경과. 8월분 미발행
9/19  청구서 2장 발행
        ① 8월분 일할   8/29~8/31 = 3일   7,000,000 × 3 ÷ 31 = 677,419원
        ② 9월분 전액   9/1~9/30          7,000,000원
      납부마감일은 둘 다 9/30
```

합산하지 않는 이유는 어느 월의 요금인지 구분되어야 하기 때문이다.

### 4.2.5 정산 항목의 부분 기간

정산 항목(전기·수도 등)은 일할 계산을 시스템에서 수행하지 않는다.
산정 기간이 달력 월과 어긋나는 경우가 많아 규칙으로 고정하기 어렵다.

담당자가 해당 유닛의 금액을 직접 계산해 입력하고 사유를 기록한다. → 4.1.9

### 4.2.6 단수 처리

> **⚠️ 확인 필요**
> 일할 계산 및 안분 결과의 단수 처리 방식이 미확정이다.
> 원 단위 절사를 기본으로 제안하나, 절사분 누적으로 합계가 고지서와 어긋날 수 있으므로
> **최종 유닛에 차액을 가산하는 방식**을 병행할지 확정이 필요하다.

## 4.3 수납 배분

### 4.3.1 배분 순서

입금 1건을 청구 여러 건에 충당하는 순서다.

```
① 입금액이 특정 청구 건 또는 청구 건들의 합계와 정확히 일치하면 그 건에 배분
② 일치하는 조합이 없으면
     오래된 청구년월부터
     → 같은 회차 안에서는 우선순위가 낮은 번호부터
```

①이 필요한 이유는 임차인이 임대료와 관리비를 분리 입금하는 사례가 있기 때문이다.
우선순위만으로 충당하면 관리비 입금이 임대료 일부로 잘못 기록된다.

배분 결과는 화면에서 수정할 수 있다. → PAY-6

### 4.3.2 검산 예시 — 부분납

```
청구 (2026년 9월분, 부가세 포함)
  임대료       7,700,000   우선순위 1
  고정관리비   1,980,000   우선순위 2
  주차비         330,000   우선순위 3
  합계        10,010,000

입금 8,000,000원 (금액 일치 조합 없음)
```

| 청구항목 | 청구액 | 배분액 | 미납액 | 납부상태 |
|---|---|---|---|---|
| 임대료 | 7,700,000 | 7,700,000 | 0 | 완납 |
| 고정관리비 | 1,980,000 | 300,000 | 1,680,000 | 부분납 |
| 주차비 | 330,000 | 0 | 330,000 | 납부전 |
| 합계 | 10,010,000 | **8,000,000** | 2,010,000 | |

### 4.3.3 검산 예시 — 금액 일치 우선

```
동일 청구 상태에서 입금 1,980,000원

① 고정관리비 1,980,000과 정확히 일치 → 고정관리비에 전액 배분
   우선순위만 적용했다면 임대료 일부로 잘못 충당된다
```

### 4.3.4 미배분 잔액

입금액이 청구액을 초과하면 잔액을 **선불임대료**(부채계정)로 예치한다.

```
입금 11,000,000 − 배분 10,010,000 = 990,000  →  선불임대료 예치
```

다음 수납 처리 시 관리자가 `선수금 사용`을 선택해 충당한다. **자동 상계하지 않는다.**
다음 회차 선납인지 착오 송금인지는 시스템이 판단할 수 없다.

## 4.4 연체료

### 4.4.1 산출식

```
연체료 = 미납액(부가세 포함) × 연체이자율 × 연체일수 ÷ 365
```

| 항목 | 값 |
|---|---|
| 연체이자율 | 계약에 등록된 값. 기본 연 8% |
| 연체일수 | 오늘 − 납부마감일 |
| 기준 금액 | **부가세를 포함한 미납액** |

### 4.4.2 검산 예시

```
미납액 1,680,000원 · 연체이자율 8% · 연체일수 12일

연체료 = 1,680,000 × 0.08 × 12 ÷ 365 = 4,418.63 → 4,418원   (원 단위 절사 기준)
```

### 4.4.3 청구 처리

- 연체료는 **표시만 하며 자동으로 청구하지 않는다**
- 관리자가 `연체료 청구`를 실행했을 때만 청구 항목이 생성되고 원장에 기록된다
- 연체료는 **과세 항목**이다. 산출액을 공급가액으로 보고 부가세를 별도 가산한다

며칠 경과한 건은 실무상 청구하지 않는 경우가 많다.
자동 청구 시 임차인과의 관계가 악화되므로 판단을 관리자에게 맡긴다.

> **⚠️ 확인 필요**
> 산출된 연체료를 공급가액으로 볼지 부가세 포함액으로 볼지 확정이 필요하다.
> 현재는 공급가액으로 보고 부가세를 가산하는 방식으로 기술했다.

## 4.5 공실률

```
공실률 = 공실 유닛 수 ÷ (전체 유닛 수 − 비운영중 유닛 수)
```

| 유닛상태 | 분자 | 분모 |
|---|---|---|
| 공실 | 포함 | 포함 |
| 사용중 | 제외 | 포함 |
| 비운영중 | 제외 | **제외** |

비운영중은 임대 대상이 아니므로 분모에서 제외한다.
관리사무소·기계실·건물주 직접 사용·장기 대수선 등이 해당한다.

준비중 계약이 있는 유닛은 **공실로 집계**한다. 임대료가 발생하지 않는 상태이기 때문이다.
계약이 확보된 사실은 유닛 목록의 임차인명으로 확인한다.

## 4.6 은행 거래내역 매칭

### 4.6.1 처리 절차

```
① 파일 업로드 및 건물 선택
     건물마다 운영계좌가 다르므로 매칭 대상을 해당 건물의 계약으로 한정
② 컬럼 매핑                 거래일시 / 거래구분 / 입금자명 / 입금액
     은행별로 저장해 재사용
③ 입금 건 추출               입금액 > 0 인 행만. 수수료 등 출금 행 제외
④ 입금자명 정규화
⑤ 매칭
⑥ 관리자 승인 → 원장 기록
```

### 4.6.2 입금자명 정규화

비교 전 다음을 제거한다.

```
공백
법인격 표기   (주)  ㈜  주식회사  (유)  ㈲  유한회사
```

### 4.6.3 매칭 규칙

**자동 매칭은 계약에 등록된 입금자명 별칭과 일치하는 경우에만 수행한다.**

| 결과 | 조건 | 처리 |
|---|---|---|
| 자동 매칭 | 별칭 일치 | 대응 계약 지정 |
| 후보 제시 | 상호 앞자리 부분 일치 | 참고 표시만. 자동 확정하지 않음 |
| 미매칭 | 위 조건 미충족 | 관리자가 계약 직접 지정 |

미매칭 건을 수동 지정할 때 해당 입금자명을 **별칭으로 등록할지 묻는다.**
등록 후에는 자동으로 매칭되므로 운용 기간이 길어질수록 자동화율이 상승한다.

### 4.6.4 별칭 기반 식별을 채택한 이유

실제 은행 거래내역의 입금자명은 상호와 일치하지 않는다.

| 실제 표기 | 문제 |
|---|---|
| `(주)케이더블유인터` | 적요 길이 제한으로 상호 절단 |
| `ICB` | 영문 약어 |
| `AMADEUS KO` | 영문 약어 + 절단 |
| `유한회사 고우컴퍼니` | 법인격 표기 방식 상이 |

상호 대조로는 식별할 수 없으며, 명칭 유사도로 자동 매칭하면 다른 계약에 입금이 기록된다.

### 4.6.5 다건 입금 처리

동일 입금자명의 입금이 여러 건이면 **묶어서 한 계약에 배분**할 수 있다.
임차인이 임대료와 관리비를 분리 입금하는 사례가 있기 때문이다.

```
예) 에스씨케이컴퍼니  7,549,294   13:05:37
    에스씨케이컴퍼니 13,200,000   13:05:36
    → 합계 20,749,294원을 한 계약에 배분
```

### 4.6.6 승인 절차

자동 매칭 결과는 **관리자 승인 후에만** 원장에 기록한다.
매칭 오류 시 다른 계약에 입금이 기록되며, 원장은 사후 정정이 어렵다.
