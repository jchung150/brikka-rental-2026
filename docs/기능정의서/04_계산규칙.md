# 4. 계산 규칙

본 장은 금액을 산출하는 규칙을 정의한다.
**오구현 시 금액이 틀어지는 부분이므로 예시 검산을 함께 제시한다.**
구현 후 본 장의 예시로 검증한다.

---

## 4.1 공용 관리비 안분

### 4.1.1 개념

상업용 관리비는 정액이 아니라 **건물 단위 고지서를 유닛에 배분한 결과**다.
단일 계약 정보만으로 금액을 산출할 수 없으며, 동일 건물 내 타 유닛의 면적과 검침값이 필요하다.

| 용어 | 정의 |
|---|---|
| 고지서 총사용량 | 한국전력·상수도사업본부 등이 청구한 건물 전체 사용량 |
| 검침 사용량 | 유닛별 계량기 값의 당월 − 전월 차이. **원본이며 수정하지 않는다** |
| 공용 사용량 | 고지서 총사용량 − Σ 검침 사용량. 복도·승강기·주차장 등에서 쓴 양 |
| 조정 배수 | 유닛별 공용부 부담을 가감한다. 기본값 1.0. **공용 사용량을 나누는 비율에만 적용한다** |
| 공용 배분 | 공용 사용량 중 해당 유닛이 부담하는 몫 |

### 4.1.2 산정 규칙

```
1) 검침 사용량   = 당월 검침값 − 전월 검침값              계량기 보유 유닛만
                   원본이다. 조정 배수를 곱하지 않는다.
2) 공용 사용량   = 고지서 총사용량 − Σ 검침 사용량
                   (검침분 미청구 건물은 고지서가 이미 공용분이므로 공용 = 총사용량)
3) 기본 가중치
      배분 기준 = 사용량   →  검침 사용량
      배분 기준 = 임대면적 →  임대면적
      ※ 안분 제외 유닛은 가중치 산정에서 뺀다 → 4.1.7-2
4) 조정 가중치   = 기본 가중치 × 조정 배수                ← 배수는 여기서만 쓴다
5) 공용 배분     = 공용 사용량 × (조정 가중치 ÷ Σ조정 가중치)   부담 대상 유닛만
6) 유닛 총사용량 = 검침 사용량(청구 대상인 경우) + 공용 배분
7) 유닛 청구금액 = 고지서 총금액 × (유닛 총사용량 ÷ 고지서 총사용량)
8) 동일 고지서에서 발생한 타 항목도 같은 비율로 환산
      전력기금·TV수신료는 한국전력 고지서에 함께 표기되나 **독립 청구 항목**이며
      묶음이 `기타-일반내역서`라 발행 문서가 다르다 → 3.3
      배분 기준을 `검침 사용량`으로 두고 참조 항목을 전기요금으로 지정한다 → 4.1.3
```

> **⚠️ 조정 배수를 검침 사용량에 곱하지 않는다.**
> 검침값은 계량기가 실측한 전용부 사용량이다. 여기에 배수를 곱하면 임차인이 쓰지 않은 양을
> 쓴 것으로 청구하게 되고, 공용 사용량(2단계)까지 함께 틀어진다.
> 배수는 **4단계 가중치에서만** 사용한다.

> **⚠️ 5단계는 가중치를 정규화하므로 공용 사용량 총량이 변하지 않는다.**
> 한 유닛의 배수를 2.0으로 올려도 그 유닛의 공용 배분이 정확히 2배가 되지는 않는다.
> 분모(Σ조정 가중치)가 함께 커지기 때문이다. 배수의 의미는 **유닛 간 상대적 부담 비율**이며,
> 한 유닛이 더 부담한 만큼 나머지 유닛이 정확히 그만큼 덜 부담한다.

> **⚠️ 부담 대상이 아닌 유닛의 조정 배수는 결과에 영향을 주지 않는다.**
> 부담 대상이 `검침기 없는 유닛만`일 때, 계량기 보유 유닛의 가중치는 0이므로 배수를 넣어도
> 산출이 달라지지 않는다. 화면에서 해당 유닛의 배수 입력란은 비활성화한다 → PAY-10 3단계

### 4.1.3 건물·항목별 설정

배분 방식은 건물마다 다르다. 건물 상세 관리비 설정탭(PRO-3)에서 항목별로 설정한다.

**설정은 두 가지만 입력한다.** 나머지는 계량기 설정에서 자동으로 정해진다.

| 설정 | 선택지 | 기본값 |
|---|---|---|
| **배분 기준** | 임대면적 / 사용량 | 임대면적 |
| **계량기 사용 여부** | 사용 / 사용 안 함 | 사용 안 함 |
| 계량기 보유 유닛 | 유닛 선택(복수) | 계량기 사용 시 지정 |

자동으로 정해지는 값

| 설정 | 선택지 | 자동 규칙 |
|---|---|---|
| 사용분 청구 여부 | 자동 / 청구함 / 임차인 직접 납부 | 계량기 보유 유닛이 있으면 `청구함` |
| 남은 금액 부담 대상 | 자동 / 전체 유닛 / 검침기 없는 유닛만 | 일부 유닛만 계량기를 보유하면 `검침기 없는 유닛만`, 그 외 `전체 유닛` |

두 값은 **예외적인 경우에만 직접 지정한다.** 건물 전 유닛이 공급자에게 직접 납부해
고지서가 공용분만 발행되는 경우가 해당한다 → 4.1.5

| 설정 | 선택지 | 용도 |
|---|---|---|
| **참조 항목** | 자기 검침값 / 타 항목 검침값 | 배분 기준이 사용량이면서 자체 계량기가 없는 항목에 지정한다. 예: 전력기금은 전기요금 검침값을 참조 |
| **안분 제외 유닛** | 유닛 선택 (복수) | 해당 항목의 안분에서 제외할 유닛 → 4.1.7-2 |

`자동`은 다음 규칙을 따른다.

```
검침기 없는 유닛 없음  →  공용분을 전체 유닛에 사용량 비율로 배분
검침기 없는 유닛 있음  →  공용분을 검침기 없는 유닛에 임대면적 비율로 배분
```

### 4.1.4 검산 예시 1 — 전기 (건물 일괄, 전 유닛 계량기)

```
고지서      10,000 kWh / 5,000,000원
유닛        A 검침 3,000   B 검침 2,000   C 검침 1,000
조정 배수   A 1.0   B 1.0   C 2.0     ← C는 1층 상가. 공용 화장실·주차장 사용이 많아 부담 가중
설정        검침분 청구함 / 부담 대상 전체 / 배분 기준 사용량
```

| 단계 | A | B | C | 합계 |
|---|---|---|---|---|
| 1) 검침 사용량 | 3,000 | 2,000 | 1,000 | 6,000 |
| 2) 공용 사용량 | | | | **4,000** |
| 4) 조정 가중치 | 3,000 | 2,000 | **2,000** (1,000×2.0) | 7,000 |
| 5) 공용 배분 | 1,714.3 | 1,142.9 | 1,142.9 | 4,000 ✓ |
| 6) 유닛 총사용량 | 4,714.3 | 3,142.9 | 2,142.9 | **10,000** ✓ |
| 7) 청구금액 | 2,357,142 | 1,571,429 | 1,071,429 | **5,000,000** ✓ |

C의 배수 2.0은 C의 **공용 배분에만** 작용한다. 검침 1,000kWh는 그대로 C에게 청구된다.
배수가 1.0일 때 C의 공용 배분은 800.0인데, 2.0으로 올리면 1,142.9가 되고
그만큼 A·B의 공용 배분이 줄어든다. 공용 사용량 4,000kWh는 변하지 않는다.

### 4.1.5 검산 예시 2 — 전기 (공용부만, 임차인 직접 납부)

전용부는 임차인이 한국전력에 직접 납부하고, 건물은 공용분 고지서만 수령하는 경우다.
유닛 검침은 수행하되 **배분 비율 산출에만 사용**한다.

```
고지서      3,000 kWh / 1,500,000원       ← 이미 공용분
유닛 검침   A 3,000   B 2,000   C 1,000 (배수 2.0)
설정        검침분 임차인 직접 납부 / 부담 대상 전체 / 배분 기준 사용량
```

| 단계 | A | B | C | 합계 |
|---|---|---|---|---|
| 2) 공용 사용량 | | | | **3,000** (총사용량 그대로) |
| 4) 조정 가중치 | 3,000 | 2,000 | 2,000 | 7,000 |
| 5) 공용 배분 | 1,285.7 | 857.1 | 857.1 | 3,000 ✓ |
| 6) 유닛 총사용량 | 1,285.7 | 857.1 | 857.1 | 3,000 ✓ |
| 7) 청구금액 | 642,858 | 428,571 | 428,571 | **1,500,000** ✓ |

검침분을 청구하지 않으므로 6단계에서 검침 사용량을 더하지 않는다.

### 4.1.6 검산 예시 3 — 상하수도 (일부 유닛만 계량기)

```
고지서      1,000 톤 / 2,000,000원
1층 카페    계량기 있음. 검침 300톤. 임대면적 100㎡
2층         계량기 없음. 임대면적 200㎡. 조정 배수 1.5   ← 식당. 공용 급수 사용이 많음
3층         계량기 없음. 임대면적 300㎡
설정        검침분 청구함 / 부담 대상 검침기 없는 유닛만 / 배분 기준 면적
```

| 단계 | 1층 | 2층 | 3층 | 합계 |
|---|---|---|---|---|
| 1) 검침 사용량 | 300 | — | — | 300 |
| 2) 공용 사용량 | | | | **700** |
| 4) 조정 가중치 (면적×배수) | 부담 대상 아님 | **300** (200×1.5) | 300 | 600 |
| 5) 공용 배분 | — | 350 | 350 | 700 ✓ |
| 6) 유닛 총사용량 | 300 | 350 | 350 | **1,000** ✓ |
| 7) 청구금액 | 600,000 | 700,000 | 700,000 | **2,000,000** ✓ |

1층은 검침분 300톤만 부담하고 공용 배분을 받지 않는다.
2층의 배수를 올린 만큼 3층 부담이 줄어들며, 공용 사용량 700톤은 변하지 않는다.
1층은 부담 대상이 아니므로 1층에 배수를 넣어도 결과가 달라지지 않는다.

### 4.1.7 공실 유닛 처리

**공실 유닛도 다른 유닛과 동일하게 가중치대로 안분에 참여한다. 별도 규칙을 두지 않는다.**
공실 유닛에 산출된 금액은 청구서를 생성하지 않으며 건축주가 부담한다.

결과는 배분 기준에 따라 달라진다.

| 배분 기준 | 공실 유닛의 몫 | 결과 |
|---|---|---|
| 사용량 비율 | 검침 사용량이 0에 가까워 몫도 0에 가까움 | 공용분 대부분을 임차 유닛이 부담. 공실이 늘면 임차인 부담이 증가 |
| 임대면적 비율 | 임대면적만큼 몫 발생 | 공실 면적분을 건축주가 부담 |

**어느 기준을 쓸지는 건물·항목별로 설정한다**(PRO-3 관리비 설정탭). 임대차계약서의 관리비 조항에 맞춘다.
예: A건물은 공용 전기요금을 사용량, 수도요금을 면적으로 배분하고 B건물은 그 반대로 설정할 수 있다.

검산 (예시 1에 공실 D호 추가. 배분 기준 사용량)

```
D호 공실 · 검침 사용량 100 (대기전력 등)

검침 사용량   A 3,000  B 2,000  C 1,000  D 100          합 6,100
공용 사용량   10,000 − 6,100 = 3,900
조정 가중치   A 3,000  B 2,000  C 2,000(×2.0)  D 100    합 7,100
공용 배분     A 1,647.9  B 1,098.6  C 1,098.6  D 54.9   합 3,900 ✓
유닛 총사용량  A 4,647.9  B 3,098.6  C 2,098.6  D 154.9  합 10,000 ✓

D호 몫 154.9kWh(77,465원)는 청구서를 생성하지 않는다 → 공실·미청구분
```

### 4.1.7-2 안분 제외 유닛

**임차인이 공급자와 직접 계약한 유닛은 해당 항목의 안분에서 제외한다.**
예: 1층 상가가 상수도사업본부와 별도 수용가로 계약한 경우.

```
직접 계약   건물 고지서에 해당 유닛의 사용량·금액이 처음부터 포함되지 않는다
            → 배분 모수에서도 제외해야 총액이 일치한다
```

| 배분 기준 | 제외 처리 |
|---|---|
| 사용량 비율 | 해당 유닛의 검침 사용량을 Σ가중치에서 제외 |
| 임대면적 비율 | 해당 유닛의 임대면적을 Σ가중치에서 제외 |

배분 기준과 무관하게 **가중치 산정에서 빼는 것으로 동일하게 처리**한다.
제외 유닛에는 해당 항목의 청구 건을 생성하지 않으며, 공실·미청구분에도 포함하지 않는다.

**설정과 기록**
- 건물 관리비 설정(PRO-3)에서 항목별로 지정한다. 유닛 단위 설정이 아니라 **항목의 배분 규칙**이다.
  동일 유닛이 전기는 건물 일괄이고 수도만 직접 계약일 수 있다
- **사유와 적용 시작일을 필수로 기록한다.** 타 임차인이 형평성을 문제 삼을 때 근거가 된다
- 적용 시작일 이전 회차의 정산 결과는 변경하지 않는다

**건물 계량기 내부에 있으면서 별도 정산하는 경우는 제외 대상이 아니다.**
고지서에 사용량이 포함되므로 `검침분 청구함`으로 처리하면 된다. 검침 사용량만큼이
해당 유닛의 청구액이 되고 나머지가 공용분으로 배분된다.

검산 (예시 3에서 1층 카페를 수도요금 안분 제외로 변경. 배분 기준 면적)

```
고지서      640톤 / 1,280,000원          ← 1층분이 빠진 금액으로 발행됨
1층 카페    안분 제외 (직접 계약)
2층         임대면적 200㎡
3층         임대면적 300㎡

Σ가중치      200 + 300 = 500              ← 1층 100㎡ 제외
공용 배분    2층 256  3층 384              합 640 ✓
청구금액     2층 512,000  3층 768,000      합 1,280,000 ✓
```

1층을 모수에 넣으면 고지서에 없는 사용량을 배분하게 되어 총액이 어긋난다.

### 4.1.8 검증 규칙

정산 확정 시 항목별로 다음을 검증한다. 불일치 시 확정할 수 없다.

```
임차인 청구액 합계 + 공실·미청구분 = 고지서 총금액
```

안분 제외 유닛은 양변 어디에도 포함되지 않는다 → 4.1.7-2

산출 결과에 `공실·미청구분`을 별도 행으로 표시해 건축주 부담액을 확인할 수 있게 한다.

### 4.1.9 산정 기간

전기·수도의 산정 기간은 달력 월과 어긋나는 경우가 많다(예: 매월 10일~익월 9일).
**본 시스템은 산정 기간을 관리하지 않는다.** 담당자가 고지서 기준으로 금액을 입력한다.

입주·퇴거로 기간이 일부만 해당하는 유닛은 담당자가 직접 계산해 금액을 덮어쓰고 사유를 기록한다.
시스템은 검침과 안분까지만 자동 처리한다.

## 4.2 일할 계산

### 4.2.1 원칙

해당 기간의 **실일수**를 기준으로 한다. **시작일과 퇴거일을 모두 포함**한다.

```
청구액 = 월 약정액 × 청구 대상 일수 ÷ 해당 기간 총일수
```

30일 고정 방식을 사용하지 않는다. 달마다 초과 징수되어 연간 합계가 어긋나기 때문이다.

### 4.2.2 첫 달

```
임대료 7,000,000원 · 계약시작일 2026-08-13

대상 기간   8/13 ~ 8/31 = 19일     (시작일 포함)
총일수      8월 = 31일
청구액      7,000,000 × 19 ÷ 31 = 4,290,322.58 → 4,290,322원
```

### 4.2.3 마지막 달 (계약 해지)

퇴거일 당일까지 임차인이 부담한다. 퇴거 당일에 이사하는 사례가 많기 때문이다.

해지일은 사전에 확정되므로 **청구서 발행 시점에 일할을 반영한다.**
해지일이 입력된 계약은 고정액 항목(임대료·고정관리비)을 시스템이 자동으로 일할 계산한다.
정산 항목은 담당자가 직접 입력한다. → 4.2.5

| 경우 | 처리 |
|---|---|
| 해지일이 당월 청구일 이후 | 당월 청구서에 일할을 반영해 발행 |
| 해지일이 당월 청구일 이전 | 당월 청구서를 발행하지 않음. 일할분은 **퇴거 정산 청구서**로 생성해 보증금에서 차감 |
| 청구서 발행 후 해지 확정 | 발행된 청구서는 변경하지 않음. 차액은 퇴거 정산에서 보증금 환급액에 가감 |

```
임대료 7,000,000원 · 청구일 매월 19일

① 해지일 10/25   10/19 발행 청구서에 일할 반영
                 7,000,000 × 25 ÷ 31 = 5,645,161원

② 해지일 10/5    10월 청구서 미발행. 9월분까지 정상 청구
                 5일분 7,000,000 × 5 ÷ 31 = 1,129,032원 → 퇴거 정산 청구서
```

**퇴거 정산 청구서의 원장 처리**

```
청구            일할분 (수익계정 증가)
수납            결제수단 '보증금상계' (수익계정 감소)
보증금 차감     동일 금액 (부채계정 감소)
보증금 환급     잔여 보증금 (부채계정 감소)
```

퇴거 정산 청구서는 CTR-3 해지 처리 과정에서 생성한다. 임차인 발송은 선택 사항이다.
보증금에서 차감하더라도 임대료 수익과 세금계산서의 근거가 원장에 남아야 하므로 청구서를 생성한다.

### 4.2.4 청구일 경과 후 계약 시작

계약이 시작된 회차의 청구일이 이미 경과한 경우, 다음 회차 청구일에 **청구서를 2장 발행**한다.

```
계약시작일 2026-08-29 · 청구일 매월 19일 · 납부마감일 매월 말일

8/19  이미 경과. 8월분 미발행
9/19  청구서 2장 발행
        ① 8월분 일할   8/29~8/31 = 3일   7,000,000 × 3 ÷ 31 = 677,419원
        ② 9월분 전액   9/1~9/30          7,000,000원
      납부마감일은 둘 다 9/30
```

합산하지 않는 이유는 어느 월의 요금인지 구분되어야 하기 때문이다.

### 4.2.5 정산 항목의 부분 기간

정산 항목(전기·수도 등)은 일할 계산을 시스템에서 수행하지 않는다.
산정 기간이 달력 월과 어긋나는 경우가 많아 규칙으로 고정하기 어렵다.

담당자가 해당 유닛의 금액을 직접 계산해 입력하고 사유를 기록한다. → 4.1.9

### 4.2.6 단수 처리

| 단계 | 규칙 |
|---|---|
| 항목별 금액 | 안분·일할 산출 결과는 **원 미만 절사** |
| **청구서 합계** | **100원 미만 자동 절사** |
| 공급가액·부가세 | 절사 후 합계에서 역산. 공급가액 = 합계 ÷ 1.1 (원 미만 절사), 부가세 = 합계 − 공급가액 |

청구서 합계의 절사액은 **청구서 내 우선순위가 가장 낮은 항목의 금액에서 차감**하고,
해당 청구 건에 절사액을 기록한다. 청구서에는 `단수 절사` 행으로 표시한다.

```
임대료          7,700,000
고정관리비      1,980,000
전기요금          682,347   → 절사 후 682,300 으로 청구 (절사액 47 기록)
단수 절사             −47   ← 청구서 표시용 행
──────────────────────────
합계           10,362,300      (절사 전 10,362,347)
```

절사액을 별도의 음수 청구 건으로 두지 않는다. 임차인이 청구서 합계를 입금했을 때
항목별 배분 합계와 일치해야 완납으로 처리되기 때문이다.

정산 항목의 절사 차액(원 미만 절사분 포함)은 PAY-10 산출 결과의 `공실·미청구분`에 흡수한다.
검증식 `임차인 청구액 합계 + 공실·미청구분 = 고지서 총금액`은 항상 성립한다.

## 4.3 수납 배분

### 4.3.1 배분 순서

입금 1건을 청구 여러 건에 충당하는 순서다.

```
① 입금액이 특정 청구 건 또는 청구 건들의 합계와 정확히 일치하면 그 건에 배분
② 일치하는 조합이 없으면
     오래된 청구년월부터
     → 같은 회차 안에서는 우선순위가 낮은 번호부터
```

①이 필요한 이유는 임차인이 임대료와 관리비를 분리 입금하는 사례가 있기 때문이다.
우선순위만으로 충당하면 관리비 입금이 임대료 일부로 잘못 기록된다.

배분 결과는 화면에서 수정할 수 있다. → PAY-6

### 4.3.2 검산 예시 — 부분납

```
청구 (2026년 9월분, 부가세 포함)
  임대료       7,700,000   우선순위 1
  고정관리비   1,980,000   우선순위 2
  주차비         330,000   우선순위 3
  합계        10,010,000

입금 8,000,000원 (금액 일치 조합 없음)
```

| 청구항목 | 청구액 | 배분액 | 미납액 | 납부상태 |
|---|---|---|---|---|
| 임대료 | 7,700,000 | 7,700,000 | 0 | 완납 |
| 고정관리비 | 1,980,000 | 300,000 | 1,680,000 | 부분납 |
| 주차비 | 330,000 | 0 | 330,000 | 납부전 |
| 합계 | 10,010,000 | **8,000,000** | 2,010,000 | |

### 4.3.3 검산 예시 — 금액 일치 우선

```
동일 청구 상태에서 입금 1,980,000원

① 고정관리비 1,980,000과 정확히 일치 → 고정관리비에 전액 배분
   우선순위만 적용했다면 임대료 일부로 잘못 충당된다
```

### 4.3.4 미배분 잔액

입금액이 청구액을 초과하면 잔액을 **미배분 상태로 입금 기록에 보관**한다.
별도 계정으로 예치하지 않는다.

```
입금 11,000,000 − 배분 10,010,000 = 990,000  →  미배분
```

관리자가 다음 중 하나를 선택해 처리한다. **자동 처리하지 않는다.**

| 처리 | 원장 기록 |
|---|---|
| 환불 | `환불` 거래로 기록 |
| 다음 회차 배분 | 다음 회차 청구 발행 후 수동 배분 |

선납은 정책적으로 받지 않으므로 선불임대료 계정을 두지 않는다.
전월에 미리 수령하는 임대료는 해당 월의 임대료이며 별도 개념이 아니다.

## 4.4 연체료

### 4.4.1 산출식

```
연체료 = 미납액(부가세 포함) × 연체이자율 × 연체일수 ÷ 365
```

| 항목 | 값 |
|---|---|
| 연체이자율 | 계약에 등록된 값. 기본 연 8% |
| 연체일수 | 오늘 − 납부마감일 |
| 기준 금액 | **부가세를 포함한 미납액** |

### 4.4.2 검산 예시

```
미납액 1,680,000원 · 연체이자율 8% · 연체일수 12일

연체료 = 1,680,000 × 0.08 × 12 ÷ 365 = 4,418.63 → 4,418원   (원 단위 절사 기준)
```

### 4.4.3 청구 처리

- 연체료는 **표시만 하며 자동으로 청구하지 않는다**
- 관리자가 `연체료 청구`를 실행했을 때만 청구 항목이 생성되고 원장에 기록된다
- **산출된 연체료는 부가세 포함 금액이다.** 기준 금액(미납액)이 부가세 포함이므로 산출액도 부가세 포함으로 본다. 별도로 부가세를 가산하지 않는다
- 연체료는 과세 항목이므로 공급가액과 부가세는 역산해 기록한다

```
연체료(합계) 4,418원  →  공급가액 4,418 ÷ 1.1 = 4,016원 · 부가세 402원
```

며칠 경과한 건은 실무상 청구하지 않는 경우가 많다.
자동 청구 시 임차인과의 관계가 악화되므로 판단을 관리자에게 맡긴다.

## 4.5 공실률

```
공실률 = 공실 유닛 수 ÷ (전체 유닛 수 − 비운영중 유닛 수)
```

| 유닛상태 | 분자 | 분모 |
|---|---|---|
| 공실 | 포함 | 포함 |
| 사용중 | 제외 | 포함 |
| 비운영중 | 제외 | **제외** |

비운영중은 임대 대상이 아니므로 분모에서 제외한다.
관리사무소·기계실·건물주 직접 사용·장기 대수선 등이 해당한다.

준비중 계약이 있는 유닛은 **공실로 집계**한다. 임대료가 발생하지 않는 상태이기 때문이다.
계약이 확보된 사실은 유닛 목록의 임차인명으로 확인한다.

## 4.6 은행 거래내역 매칭

### 4.6.1 처리 절차

```
① 파일 업로드 및 건물 선택
     건물마다 운영계좌가 다르므로 매칭 대상을 해당 건물의 계약으로 한정
② 컬럼 매핑                 거래일시 / 거래구분 / 입금자명 / 입금액
     은행별로 저장해 재사용
③ 입금 건 추출               입금액 > 0 인 행만. 수수료 등 출금 행 제외
④ 입금자명 정규화
⑤ 매칭
⑥ 관리자 승인 → 원장 기록
```

### 4.6.2 입금자명 정규화

비교 전 다음을 제거한다.

```
공백
법인격 표기   (주)  ㈜  주식회사  (유)  ㈲  유한회사
```

### 4.6.3 매칭 규칙

**자동 매칭은 임차인(사업자)에 등록된 입금자명 별칭과 일치하는 경우에만 수행한다.**
별칭은 사업자 단위로 등록한다. 은행에 표기되는 입금자명은 계약이 아닌 사업자의 속성이며,
사업자 단위로 두면 재계약·추가 계약 시에도 매칭이 유지된다.

| 결과 | 조건 | 처리 |
|---|---|---|
| 자동 매칭 | 별칭 일치 + 선택한 건물에 해당 사업자의 계약이 1건 | 대응 계약 지정 |
| 후보 제시 | 별칭 일치 + 선택한 건물에 해당 사업자의 계약이 복수 | 계약 후보를 제시. 입금액이 미납액과 일치하는 계약을 우선 표시. 관리자가 선택 |
| 후보 제시 | 상호 앞자리 부분 일치 | 참고 표시만. 자동 확정하지 않음 |
| 미매칭 | 위 조건 미충족 | 관리자가 계약 직접 지정 |

미매칭 건을 수동 지정할 때 해당 입금자명을 **별칭으로 등록할지 묻는다.**
등록 후에는 자동으로 매칭되므로 운용 기간이 길어질수록 자동화율이 상승한다.

### 4.6.4 별칭 기반 식별을 채택한 이유

실제 은행 거래내역의 입금자명은 상호와 일치하지 않는다.

| 실제 표기 | 문제 |
|---|---|
| `(주)케이더블유인터` | 적요 길이 제한으로 상호 절단 |
| `ICB` | 영문 약어 |
| `AMADEUS KO` | 영문 약어 + 절단 |
| `유한회사 고우컴퍼니` | 법인격 표기 방식 상이 |

상호 대조로는 식별할 수 없으며, 명칭 유사도로 자동 매칭하면 다른 계약에 입금이 기록된다.

### 4.6.5 다건 입금 처리

동일 입금자명의 입금이 여러 건이면 **묶어서 한 계약에 배분**할 수 있다.
임차인이 임대료와 관리비를 분리 입금하는 사례가 있기 때문이다.

```
예) 에스씨케이컴퍼니  7,549,294   13:05:37
    에스씨케이컴퍼니 13,200,000   13:05:36
    → 합계 20,749,294원을 한 계약에 배분
```

### 4.6.6 승인 절차

자동 매칭 결과는 **관리자 승인 후에만** 원장에 기록한다.
매칭 오류 시 다른 계약에 입금이 기록되며, 원장은 사후 정정이 어렵다.
