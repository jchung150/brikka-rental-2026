### 4.3 결정 근거 참조

각 화면의 결정 근거(「고민되는 점」)는 인수인계 문서에 원본이 있다.

```
docs/작업_인수인계.md  §5 행별 확정 내역  →  화면 ID로 검색
```

본 기능정의서에는 **구현에 영향을 주는 근거만** 「설계 의도」로 1~2줄 요약해 싣는다.
