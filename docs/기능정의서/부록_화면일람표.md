# 부록. 화면 일람표

전체 77개 화면 목록이다. 1차 35개, 2차 42개.

**화면 ID는 연속되지 않는다.** 2차로 이관한 화면의 번호를 비워 두었기 때문이다.
1차 범위에서 PAY-4 · PAY-7 · PAY-8 · USER-4 · USER-5가 결번이다. PAY-8(수납 내역 조회)은 PAY-6에 합쳤고,
PAY-4(청구 항목 관리)는 청구 항목을 건물별로 관리하게 되어 PRO-3 관리비 설정에 흡수했다.

## 3. 2차 신규 필요 기능 — 2건

기능정의서에 항목이 없는 업무다. 전환 검토 중 도출했다.

| 기능 | 내용 | 도출 |
|---|---|---|
| 건물 비용 관리 | 청소·경비 용역비, 승강기 유지보수비, 수선비, 재산세, 보험료 등 지출 항목 관리. 현재 지출 데이터가 부재하여 임대인 보고서가 손익을 제시하지 못함 | REP-1 |
| 임대인 정산·송금 | 위탁사가 수취 후 수수료를 제외하고 임대인에게 송금하는 운영 방식 지원. 현 운영 모델은 임대인 직수취형이므로 1차는 이를 전제 | USER-9 |
