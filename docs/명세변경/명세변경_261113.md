## 32. 계좌조회 업체는 바로빌 — 1시간마다 수집

**32-1. 업체**
- 명세변경_261108 24-2의 계좌조회 API 업체는 **바로빌**이다(개발자센터 https://dev.barobill.co.kr)
- 세금계산서 발행 연동(2차)도 바로빌로 한다
- 업체를 바꿔도 수집 부분만 갈아 끼우도록 만드는 원칙(24-2)은 그대로다

**32-2. 수집 주기**
- 바로빌이 은행에서 거래내역을 **1시간마다**(매시 07분경) 수집해 바로빌에 쌓는다. 시스템은 바로빌에 쌓인 내역을 가져온다(가져오는 호출은 요금이 없다)
- 24-3 「기본 1시간마다」는 이것으로 정해졌다

**32-3. 직전 수집(24-3)**
- 바로빌은 은행에서 바로 수집하는 기능이 없다. 청구서 발행 · 월 마감 · 해지 처리 저장 직전과 입금 매칭 화면을 열 때는 **바로빌에 쌓인 최신 내역을 가져오는 것**으로 한다
- 그래서 그 순간의 거래내역은 최대 1시간 전 것이다. 화면의 마지막으로 가져온 시각(24-3)에는 **BRIKKA가 바로빌에서 마지막으로 읽은 시각**을 보인다. 바로빌은 은행에서 수집한 시각을 따로 주지 않는다(확인요청_261114 답변 질문 1)
