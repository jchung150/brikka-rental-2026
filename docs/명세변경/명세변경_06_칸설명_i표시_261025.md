| 항목 | 내용 |
|---|---|

| 관련 화면 | 입력 화면 전체(먼저 CTR-2 계약 등록 · CTR-4 재계약) |

## 1. 칸 하나에 붙는 설명은 칸 옆 캡션이 아니라 ⓘ로

**v1.5 내용**
칸 하나에 붙는 짧은 설명(예: 재계약 계약상태 옆 「시작일에 진행중」)을 입력 칸 오른쪽에 작은 글씨로 붙인다.

**변경**
- 칸 이름 오른쪽에 작은 동그라미 **ⓘ**를 두고, 마우스를 올리면 설명 상자가 뜬다
- 입력 칸 옆에는 설명 글을 두지 않는다. 그래서 **같은 칸은 어느 화면에서나 폭이 같다**
- 단위(`대`, `연 %`, `%`, `개월`)와 금액 한글 읽기(`979만원`)는 칸의 일부라 그대로 둔다
- 카드 맨 위의 카드 전체 안내 문장(예: 「재계약은 같은 임차인과 맺습니다…」)은 이번 범위가 아니다
- 앞으로 새로 만드는 칸 설명도 이 방식을 쓴다

**이유**
재계약 화면에만 설명이 붙어 같은 칸인데도 계약 등록과 폭이 달랐다. 같은 종류의 화면은 같은 모양이어야 한다.

**예시 (CTR-2 · CTR-4에 적용한 것)**

| 칸 | ⓘ 설명 |
|---|---|
| 계약상태 (재계약) | 준비중으로 등록되고 계약시작일에 진행중이 됩니다 |
| 계약시작일 (재계약) | 기존 계약종료일 다음 날입니다. 고칠 수 없습니다 |
| 입금자명 | 입금자명을 등록해 두면 입금 매칭에서 자동으로 이 임차인에게 연결됩니다 |
| 중개 수수료율 | 몰라도 됩니다. 나중에 계약 상세에서 넣습니다 |
| 청구일 · 마감일 | 건물 설정에서 정합니다 |
| 임대료 기산일 · 관리비 기산일 | 그 날짜가 나온 근거(계약시작일과 같음 / 렌트프리가 끝난 다음 날 / 따로 정한 날 · 소급) |

**v1.5에서 달라지는 곳**
- 03 전역규칙 UI 공통 규칙에 「칸 하나에 붙는 설명은 칸 이름 옆 ⓘ(마우스를 올리면 표시)로 둔다」 추가
- 06 CTR-2 · CTR-4에서 칸 옆에 붙던 설명 문구는 ⓘ 설명으로 읽는다

**개발 영향**
입력 줄 컴포넌트에 설명(tip) 값 하나를 받게 한다. 설명 상자는 카드 밖으로도 보이게 화면 기준으로 띄운다.
