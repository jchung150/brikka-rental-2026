| 항목 | 내용 |
|---|---|
| 기준 명세 | 기능정의서 v1.5 (2026-10-07, 개발자 전달본) |
| 작성일 | 2026-10-25 |
| 상태 | **대표 검토 중 · 개발자 미전달** |
| 관련 화면 | CTR-2 계약 등록, CTR-4 재계약, CTR-3 계약 상세(보증금 정보 카드 · 수정 패널) |

## 1. 보증금 반환일은 입력받지 않고 자동으로 정한다

**v1.5 내용**
보증금 반환예정일을 입력받는다. 기본값은 계약종료일이고, 직접 고치면 그 값을 유지한다. 계약 등록 · 재계약 · 계약 상세 보증금 수정 패널에 칸이 있다.

**변경**
반환예정일 칸을 모든 화면에서 없앤다. 보증금 반환일은 시스템이 정한다.

| 경우 | 보증금 반환일 |
|---|---|
| 평소 | 계약종료일 |
| 해지한 계약 | 해지일 |

계약 상세 보증금 정보 카드에는 「보증금 반환일」을 읽기 전용으로 보여 준다. 옆에 근거를 작게 적는다(`계약종료일 · 해지하면 해지일` 또는 `해지일`).

**이유**
- 반환일은 계약종료일이나 해지일로 이미 정해진다. 따로 입력하면 두 날짜가 어긋날 수 있다
- 이 날짜를 쓰는 계산이나 알림이 없다. 화면에 보여 주는 값일 뿐이다
- v1.5에 이 칸이 왜 필요한지 적힌 근거가 없다

**예시**
- 2024.03.01 - 2028.02.28 계약 → 보증금 반환일 2028.02.28
- 같은 계약을 2027.06.30에 해지 → 보증금 반환일 2027.06.30

**v1.5에서 달라지는 곳**
- 02 도메인모델 「보증금: 약정액·반환예정일」 → 「보증금: 약정액」
- 06 CTR-2 보증금 입력 항목에서 「보증금 반환예정일」 삭제. 「보증금 반환예정일은 계약종료일을 기본값으로 따라간다. 직접 고치면 그 값을 유지한다」 삭제
- 06 CTR-3 보증금 정보 카드 「보증금 반환예정일」 → 「보증금 반환일(계약종료일, 해지하면 해지일. 읽기 전용)」. 수정 패널에서 「보증금 반환예정일」 삭제
- 06 CTR-4 입력 항목에서 「보증금 반환예정일(디폴트: 계약종료일)」 삭제
- 10 데이터요구사항 「보증금 약정액 · 반환예정일」 → 「보증금 약정액」
- 명세변경 01 표의 「보증금 반환예정일」도 함께 지운다

**개발 영향**
계약 테이블에 반환예정일 칸이 필요 없다. 화면에는 `해지일 ?? 계약종료일`을 계산해서 보여 준다.
