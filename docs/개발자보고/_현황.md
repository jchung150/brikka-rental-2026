## 확인 필요 (대표 조치)

- **명세변경 01·02가 개발자에게 전달되지 않은 것으로 보인다.** 두 문서 모두 상태가 「개발자 미전달」이고,
  3주차 보고가 납부 안내 시점(Q10)을 여전히 미결로 분류한다. 재계약 규칙 6건도 미전달. 코딩 착수(10.26) 전에 전달한다
- **감액 수정세금계산서의 기록 범위가 다르다.** 명세변경 02 §8은 감액 기록에 「수정 발행 대상」 표시와
  차감 공급가액·부가세를 남기도록 확정했으나, 3주차 보고는 「원장만 보관」으로 적었다. 스키마에 칸이 없으면 나중에 고쳐야 한다

## 기록 규칙

- 보고서를 받으면 원문 PDF를 그대로 저장한다. 구글 문서 링크(`.gdoc`)는 본문이 없으므로 두지 않는다
- 첨부 파일은 `첨부/`에 원래 이름 + 날짜로 둔다
- 이 파일의 표 네 개를 같이 갱신한다. 숫자가 전주와 같으면 **그 사실을 비고에 적는다**
- Change Order §5.2가 지연 기산점을 「개발자 주간보고에 기록된 요청일」로 정하므로, 원문을 고치지 않고 그대로 보관한다
