# 개발자 주간보고 — 누적 현황

David Cho(독립계약자)가 계약 §3.2에 따라 매주 제출하는 보고의 요약이다.
원문은 같은 폴더의 `개발자주간보고_NN_YYMMDD.md`에 둔다.

**이 표를 쓰는 이유** — 보고서를 한 건씩 읽으면 주차 간 변화를 놓친다.

## 기록 규칙

- 보고서를 받으면 원문을 `개발자주간보고_NN_YYMMDD.md`로 저장한다(NN = David의 주차 번호, 날짜 = 보고 기간 종료일)
- 첨부 파일은 `첨부/`에 원래 이름 + 날짜로 둔다
- 이 파일의 표 네 개를 같이 갱신한다. 숫자가 전주와 같으면 **그 사실을 비고에 적는다**
- Change Order §5.2가 지연 기산점을 「개발자 주간보고에 기록된 요청일」로 정하므로, 원문을 고치지 않고 그대로 보관한다
