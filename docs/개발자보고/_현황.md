- 「Executive Summary」가 1주차 문장 그대로다 — `Development environment initialization and repository setup are underway`.
  앱 셸이 완료된 지금은 사실과 다르다. 복사 흔적이다
- 요청할 것: **리스크 표에 최소한 ①구조 결정 미해소 ②스키마 재작업 ③Stage 1 납품물 ② 준비 상태를 적는다**

### 4. ★ Stage 1만 미루면 뒤 구간이 좁아진다 — 대표만 보는 숫자
