표 4. 자동 수집 방식
항목내용
업체바로빌. 2차의 세금계산서 발행 연동도 같은 업체로 묶습니다. 업체를 바꿔도 수집 부분만 갈아 끼우는 구조는 그대로 유지

화면 표시청구서 발행 · 월 마감 · 해지 처리 화면에 마지막으로 가져온 시각을 보입니다 (예: 거래내역 11.19 09:05까지). 담당자가 보고 판단합니다

미지원 은행바로빌이 지원하지 않는 은행 통장은 자동 수집 안 함으로 두고 엑셀 업로드 · 직접 입력으로 운영합니다
출금 내역가져오지 않습니다. 출금 대조는 2차 그대로
