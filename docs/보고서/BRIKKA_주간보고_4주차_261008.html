  • 건물 상세 — 요약 · 유닛 · 주차 · 관리비 · 자료보관 · 이력 6개 탭

  • 추가·수정·삭제를 모두 오른쪽 패널로 통일. 화면마다 다른 방식을 두지 않음

이번 주 목업에서 확정한 업무 규칙

  • 청구일·납부마감일은 건물에 하나. 발행한 청구서는 날짜를 고정하고 다시 계산하지 않음
  • 일할 계산으로 줄어든 몫은 건축주 부담. 절사 잔차는 일할하지 않은 계약에 재배분
  • 확정한 정산은 마감을 취소해도 고치지 않음. 지난 회차 오류는 이번 회차 차액으로 처리
  • 과납은 별도 처리 없이 전월 과납액으로 이월. 환불은 계약 원장에서 수행
  • 주차는 주차면 번호가 아니라 등록 차량 단위로 관리
  • 이력은 삭제하지 않음. 슈퍼관리자가 지워도 원래 기록을 두고 삭제 기록을 남김

건물별로 임대료 납부 계좌와 관리비 납부 계좌를 각각 둘 수 있게 설계했습니다. 실제로 두 계좌를 쓰는 건물이 있는지에 따라 처리 방식이 달라집니다
확인 항목
청구서에 계좌를 어떻게 안내하는지(항목별 / 합계를 둘로 나눔) / 관리비 계좌로 들어온 입금을 임대료 미납에 충당해도 되는지 / 은행 거래내역을 계좌마다 따로 올리는지
요청 사항
실제 운영 방식 회신. 현재 수납 배분 규칙은 계좌를 구분하지 않습니다
