전환 착수 시 72개 항목의 영향도를 개략적으로 판정했으며, 일부는 “상업용에서도 유지”로 분류했습니다. 이후 항목별 상세 검토 결과, “유지” 분류 항목 중 검토 완료한 15개 전부가 구조 변경 대상으로 확인되었습니다.

2.4 작업 순서

데이터 설계는 저장 대상이 확정되어야 착수 가능합니다. “공용 전기요금 배분 기준”, “공실분 부담 주체”, “부분납 충당 순서” 등이 결정되지 않으면 테이블 설계가 불가하며, 해당 결정은 기능정의서에서 도출됩니다.

순서를 역으로 진행할 경우 미결정 사항을 개발 과정에서 임의 확정하게 되고, 해당 판단이 테이블 구조에 고정됩니다. 운영 개시 후 불일치가 확인되는 시점에는 데이터가 축적되어 구조 변경 비용이 현저히 증가합니다.

  • 2차 PG 연동 시 구조 변경이 발생하지 않도록 사전 항목 확보

  • 범위 축소에도 월 단위 업무는 시스템 내 완결
