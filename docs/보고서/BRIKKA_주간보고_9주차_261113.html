‣ 은행 거래내역 자동 수집 (명세변경 24번)

표 2. 변경 내용과 범위 영향
항목내용
무엇이 바뀌나건물 납부 계좌의 거래내역을 외부 계좌조회 API로 자동 수집합니다. 담당자가 은행에서 파일을 내려받아 올리지 않아도 입금 매칭 대기열에 입금이 쌓입니다
왜 올렸나연체료가 입금일까지 매일 쌓이므로 입금을 제때 아는 것이 청구 금액을 정합니다. 파일 업로드만 두면 올리지 않은 날의 입금을 시스템이 모르고, 이미 낸 돈이 이월 미납액으로 다시 청구됩니다
예: 11.10 입금을 모른 채 11.19 청구서 발행 → 연체료 18일분 3,945원 청구. 실제는 10일분 2,191원
범위 영향v1.5 「2차 범위」는 외부 계약 · 심사가 필요한 기능을 2차로 두었습니다. 은행 거래내역 자동 수집만 1차로 올립니다. 가상계좌 연동과 세금계산서 발행 연동은 2차 그대로입니다. Stage 1 납품물의 차수 구분표에 이 이동을 반영합니다
연동이 멈출 때거래내역이 들어오는 길을 셋으로 둡니다 — 자동 수집(평소) · 엑셀 업로드(v1.5 그대로) · 직접 입력. 셋 모두 같은 거래내역에 쌓이고 매칭 · 배분은 동일합니다. 연동이 멈춰도 업무가 멈추지 않습니다
자동 확정등록된 입금자명과 일치해 자동 매칭된 입금은 담당자 확인 없이 바로 배분합니다. 금액이 받을 돈보다 크거나 마감한 달의 입금이면 대기열에 남깁니다
업체선정 중. 기준은 법인 계좌 · 납부 계좌 은행 지원, 당일 조회, 호출 제한 · 요금, 은행 로그인 정보를 맡기지 않는 방식입니다. 업체를 바꿔도 수집 부분만 교체되도록 개발합니다

* 월 이용료 부담 주체와 임대인 계좌 조회 동의 절차는 확인이 필요합니다 → 협조 요청.

핵심 판단
