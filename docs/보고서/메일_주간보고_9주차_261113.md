안녕하세요, 테온하우스 담당자님.

9주차(11.05~11.11) 주간보고와 **기획 완료 보고서**를 첨부로 보내드립니다.

**이번 주로 1차 범위의 기획이 끝났습니다.** 명세 변경 3차(24~31번)와 개발 측 확인 요청 26건의
답을 11월 8일에 전달했고, 화면 목업의 계산 검증 141개가 통과했습니다. 기능정의서 v1.5 이후
명세 변경은 누적 30건입니다. 시스템 구조 재정비도 11월 7일에 끝나 화면 개발이 재개됐습니다.

첨부한 **기획 완료 보고서**는 흩어져 있던 기능정의서 v1.5와 명세 변경 30건, 확인 요청 답변을
한 권으로 정리한 문서입니다. 11개 장과 부록 4종으로 구성했으며, 12월 14일 Stage 1 납품물 중
기능정의서 항목의 기준 문서가 됩니다.

주간보고에서 특히 보실 부분은 두 곳입니다. 하나는 **은행 거래내역 자동 수집**으로, v1.5에서 2차로
두었던 기능을 1차로 올린 범위 변경입니다. 다른 하나는 **인증 방식 정정**으로, 8주차에 보고한
2단계 인증이 인증 앱에서 이메일 코드로 바뀌었습니다. 2단계 인증 자체는 유지됩니다.

**확인을 요청드릴 사항은 두 가지입니다.** 둘 다 은행 거래내역 자동 수집과 관련됩니다.

- **계좌조회 API 월 이용료 부담 주체** — 개발 후에도 매달 발생하는 운영 비용이며, 업체 선정
  기준에 요금이 들어가므로 선정 전에 필요합니다
- **임대인 계좌 조회 동의 절차** — 수집 대상은 건물 납부 계좌, 즉 임대인 명의 계좌이므로
  운영사가 조회할 동의나 위임이 필요합니다. 절차와 서식을 알려주시면 화면과 안내를 맞추겠습니다

8주차에 요청드린 Stage 1 일정 조정 확인과 검수 의견 회신 기한(2027년 1월 8일)은 주간보고
마지막 장에 함께 올려 두었습니다.

---

**중간 대금 요청 — CAD $10,000**

기획 산출물이 완료된 시점에 맞춰 잔금 중 **CAD $10,000의 선지급을 요청드립니다.**

Change Order 1호 §7.1은 총액 CAD $42,000이 기획 산출물을 포함한 Phase 1 전체의 대금임을
확인하고 있습니다. 그 기획 산출물이 이번 주로 완료되었습니다. 기능정의서 v1.5, 명세 변경 30건,
확인 요청 답변, 검증을 마친 화면 목업, 첨부한 기획 완료 보고서입니다.

| 항목 | 금액 |
|---|---|
| 총액 | CAD $42,000 (변동 없음) |
| 기수령 선금 | CAD $21,000 |
| **금차 요청** | **CAD $10,000** |
| 잔금 | CAD $11,000 — Phase 1 최종 검수 수락 후 10일 내 (§7.3 그대로) |

§7.4는 Stage 1 산출물 수락 시 대금이 발생하지 않는다고 정하고 있습니다. 본 요청은 그 조항과
§7.3의 지급 시기를 위와 같이 조정해 주시기를 함께 요청드리는 것입니다. **총액과 개발 범위,
Phase 1 최종 납품일(2027년 2월 12일)은 변동이 없습니다.**

회신으로 동의해 주시면 인보이스를 발행해 보내드리겠습니다.

감사합니다.
