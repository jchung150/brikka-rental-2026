그래서 미납액은 매일 바뀌지 않는다. 청구서를 발행하거나 돈이 들어올 때만 바뀐다. 은행 입금 매칭도 청구서 금액과 맞아 쉬워진다. 지금 명세변경 17-3 · 18-3의 「함께 정리」 스위치와 연체료 처리 세 버튼은 없앤다. EN: So the unpaid balance does not change every day. It changes only when an invoice is issued or money comes in. Bank deposit matching also gets easier because amounts match the invoice. The "settle together" switch and the three late fee buttons from spec changes 17-3 and 18-3 are removed.
